# v7.0.3-r7 未签名预发布版

本轮修复 Firefox 表单下载接管的重复 POST，并补充安装包的实际功能验收。没有新增播放器引擎或大型依赖，不包含用户密钥、任务库或下载文件。

## 实际缺陷与修复

旧插件在 Firefox 的 DownloadItem 先于请求链到达时，可能先走普通下载路径，随后在构造接管请求时才观察到 POST。沙盒中服务器实际收到两次表单提交，虽然成品文件正确，仍属于重复请求缺陷。

修复后，先用与接管载荷相同的流程确定请求身份，再决定是否暂停浏览器下载。POST 让浏览器原请求完成，随后导入本地文件；普通请求把已确认的同一条请求链交给桌面，避免二次解析改变接管方式。没有可验证请求链时保留浏览器下载。

专项实测核对普通表单及 multipart 表单的服务器请求次数、成品 SHA256 和文件归属：接受后只有一个桌面成品，复制成功后清理浏览器副本；取消后保留浏览器原文件，不新建桌面任务。

## 仍有边界的范围

原用户网页本轮 Firefox 访问停在 Cloudflare 的“Just a moment…”页面，没有视频元素和可识别资源；此前 Edge 被 SmartScreen 阻挡，原 surrit 清单返回 HTTP 403。未绕过这些限制，原网页和原片仍不能标记为验收通过。

字幕音频预取、伪装后缀解码和浏览器音频链路保留 r6 的实际记录；真实云端有历史短音频记录，本轮未重跑长视频翻译质量和端到端延迟。投屏与 TVBox 真实设备验收按用户既定范围排除。BT 未完成任务、直播和未知长度 HTTP 不属于已支持的边下边播范围。

vGPU 沙盒的同一 libmpv 播放 640×360 视频时，默认输出六秒样本约占整机 CPU 1.69%；禁用 GPU 沙盒此前出现约 54.6% 的边播边下样本。没有据此修改播放器配置，也不把小样本外推为所有硬件性能保证。

插件类型检查、380 项测试、Chromium/Firefox 构建和打包通过；Firefox 扩展校验零错误、零警告、零提示。交付均未签名，保留一个 main 分支和一个 worktree。
