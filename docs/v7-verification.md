## 当前实现与发布合同

`artifacts/v7-productization/feature-parity.json` 是 canonical 功能合同：`product_version=7.0.3`、29 项中 27 verified、2 partial，`release_ready=true` 带有该文件列明的排除条件。两个 partial 为浏览器媒体推送设备选择、浏览器在线字幕翻译。

r12 包的 provenance 是另一份范围明确的交付记录：`package_tier=unsigned-prerelease`、`release_ready=false`。它没有宣称同一提交的全部正式 CI、实体设备和真实云端门禁均完成。现有正式打包/发布工作流的门禁继续由脚本核对；本文不替代门禁，也不把历史测试总数套到新版本。

安装包与浏览器插件按用户要求不签名。自动更新仍执行签名和受信 signer 校验，因此当前未签名包通过 MSI 手动更新，不能关闭安全校验强行自更新。

## 尚未覆盖与运行边界

- 本轮未上传音频，不产生云端字幕服务费用；本地音频链路与历史云端证据不能证明当前服务账户、额度和网络始终可用。
- 实体投屏/TVBox、真实系统关机/睡眠不在本轮执行范围。
- Chromium 扩展构建/测试及历史接管证据不等于当前版本的 Chromium 全网页真实 UI 验收。
- 缓存清理保留用户成品、配置、密钥及备份；已被自动审批拒绝的本机构建缓存和旧包删除未重试，不得标记为已清空。
- 安装占用和 5 秒闲置 CPU/内存为一次沙盒样本，不是跨电脑性能保证。
