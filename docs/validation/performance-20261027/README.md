# 性能实测与发布整理（2026-10-27）

本轮没有保留生产性能改动，也没有删减功能或新增依赖。两个下载热路径试验出现耗时退化，均已撤回；保留了安装验收脚本的 `--idle-seconds` 参数，默认仍为 5 秒，本轮用 60 秒采样。桌面产品仍是源码 `1b5efac80c91a06c23202278f0a8ae5d0b233404` 的未签名候选，MSI SHA256 为 `140b9774ebcb457dd7875b384de055568321a171a493e7cbf2972f50d72fce96`，没有把试验 Engine 放进安装包。

## 为什么撤回

128 MiB 的无 Range GET/POST 下载，分别用 4 KiB/64 KiB 服务端写块；同一沙盒、相同工具链离线编译、两个相同 SHA 的旧版对照，三轮轮换执行顺序。检查完整字节/SHA256、请求次数、完成及删除后的缓存清理。每批 27 样本，重复一批，共 54 样本。数据属于 Core 和本地夹具，不代表互联网或整套 UI 性能。

- 顺序下载改用 256 KiB `BufWriter` 后，GET 4 KiB 中位数从约 0.32 秒变为 0.43–0.46 秒。写入次数显著减少仍不足以保留该改动；撤去额外的首块进度事件后也没有消除退化。见 [原始中位数](results/sequential-medians.json) 和 [失败记录](results/rejected-buffered-write/summary.json)。
- 限速路径试验改为只复制队列/任务作用域、查找已有桶，并在未启用时段限速时跳过取时钟。最终 GET 样本有快有慢；POST 4 KiB 两批候选中位数为 0.405/0.455 秒，对照分别为 0.377–0.380/0.379–0.402 秒。因此没有据“分配更少”宣称整体更快，全部生产改动撤回。见 [中位数](results/throttle-medians.json)、[试验差异](results/rejected-throttle.diff.txt) 和 [原始样本](results/final/sequential.json)。

中间试验的下载播放矩阵两次出现播放器状态 IPC 超时，分别在 TS 反复跳转恢复、外挂音轨初始播放阶段。原版和最终试验后来都完成了 29 个检查点；这不能证明偶发超时根因已修复。没有放宽超时或删掉失败记录。首次 Core 夹具还因缺少安装包中的图标失败，补齐客体夹具后重跑；该失败保存在 `results/first-attempt`。另一次沙盒启动失败来自报告目录尚未创建就开始映射，检查映射目录存在后重新启动。

## 实际验证范围

试验版本完整 Core 每轮 636 通过、0 失败、12 跳过；另显式运行 curl 4、WinHTTP 4、真实 FFmpeg 暂停/取消 1 项，共 645 个不同通过项。剩余 3 个跳过项未计为通过。最终试验还通过 HTTP 边界 13、卡住连接控制 6、下载播放 29 个检查点。上述结果属于对应 SHA 的试验二进制，不能转作未修改安装包的全部功能认证。

原版 Engine 的 29 项下载播放检查覆盖 HTTP、HLS TS/fMP4/AES/外挂音轨、DASH、暂停续传、未完成时跳转、独立缩略图、完成后在原窗口切换成品、关闭播放器、完成/删除/清理已完成后的缓存及无关文件保护。见 [原版结果](results/intermediate-allocation/baseline-playback.json)。

当前桌面同 SHA MSI 在沙盒进行含空格自选安装路径、全部安装文件哈希、插件 ZIP、Windows 下载 Known Folder、公开 MDN WebM 字节/SHA256、HTTP/HLS 重试与缓存清理、默认 Native Host 冷启动/并发/常驻/重启、完整 UI 连接、60 秒闲置占用和卸载验证。第一次复验结果在 [安装报告](results/intermediate-allocation/installed.json)：安装文件 469,586,795 字节；闲置工作集合计 245,198,848 字节（约 234 MiB），private 合计 276,582,400 字节，8 个客体逻辑 CPU 的整机归一占用约 0.30%。这是本轮占用基线，不是优化收益。

第一次复验的 UI 显示并连接耗时 17.922 秒，实屏截图非空，paint 截图为空；非空不等于全部按钮和视觉细节验收。安装体积主要来自既有 FFmpeg、libmpv 和 JRE，没有为缩包删除协议、格式或播放能力。没有新增本轮 UI/插件代码、宿主安装、云端调用、实体投屏、真实浏览器矩阵或长期负载验收。

旧 IDM/AB 同机 18 样本确实存在，见 [2026-10-19 对照](../idm-ab-20261019/README.md)。版本和场景有限，不能说当前包在性能、占用和全部功能上已全面相同。千任务状态事件 IPC 的本轮中间试验 P95 约 0.65–0.75 ms，不是点击、解码或全产品响应延迟。
