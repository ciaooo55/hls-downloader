## 当前实现与发布合同

`config/release/feature-parity.json` 是 canonical 功能合同：`product_version=7.0.3`、29 项中 27 verified、2 partial，`release_ready=true` 带有该文件列明的排除条件。两个 partial 为浏览器媒体推送设备选择、浏览器在线字幕翻译。

r12 包的 provenance 是另一份范围明确的交付记录：`package_tier=unsigned-prerelease`、`release_ready=false`。它没有宣称同一提交的全部正式 CI、实体设备和真实云端门禁均完成。现有正式打包/发布工作流的门禁继续由脚本核对；本文不替代门禁，也不把历史测试总数套到新版本。

安装包与浏览器插件按用户要求不签名。自动更新仍执行签名和受信 signer 校验，因此当前未签名包通过 MSI 手动更新，不能关闭安全校验强行自更新。
