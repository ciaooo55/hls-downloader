## 实现

主程序“设置 → 字幕翻译”统一保存服务提供方、百炼空间/地域、API Key、启用状态、语种、显示原文、同步模式及默认偏移。密钥沿用系统加密存储，不回显；空输入保留，清除需保存才生效。

插件保留网页/本站开关、播放器选择、开始和停止、只读配置说明。浏览器不能通过 Native Host 写全局配置；网页的临时时差保存在浏览器会话中，不覆盖主程序默认值。保存主程序配置会停止当前翻译，需要网页重新开始。
