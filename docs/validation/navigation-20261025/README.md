# 2026-10-25 侧栏筛选、连接颜色与工作台唤醒

## 改动及边界

侧栏状态、分类、队列的计数都面向整个任务库，但旧回调保留其他分组的选择，可能导致点击有计数的分类后列表为空。现在跨分组切换清除其他分组条件，保留用户显式搜索；列表标题随当前分类或队列变化。这解释了可复现的交叉筛选路径，不能据此断言用户截图中的所有点击失效都只有这个原因。

插件真实已连接时，页脚文案使用主题成功色；未连接保持灰色。没有修改连接判断或把离线伪装成在线。

Core 托盘打开工作台不再直接用 Win32 `ShowWindow` 恢复 HWND，而是启动现有工作台入口，经单实例唤醒通知在 AWT 事件线程恢复 Java 可见状态。旧路径可能出现 HWND 可见而 Java 仍隐藏的状态分歧。本轮移除这条重复窗口操作路径，没有增加依赖或轮询。

宿主现场只读调查：两条 HLS 任务均已失败，记录为清单 HTTP 403、0 字节；Core 快照即时响应，无传输或合并任务。宿主主窗口当时处于隐藏状态。这不足以证明下载线程卡死，也不足以确定直播 403 的原因。未停止、安装或更新宿主 `E:\hls` 产品，未操作用户任务、密钥和下载。
