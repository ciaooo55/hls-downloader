## 缓存生命周期

- 成品发布、字幕复制后，默认清理 HLS/DASH 分片、独立音轨、合并中间文件、下载请求体、HTTP 续传检查点和过程日志；这也覆盖普通文件与 BT 的任务工作文件。
- 成品路径及完成状态持久化成功后，删除任务控制、统计、选择表及成品定位文件；任务目录和 `.hls-tasks` 容器为空时一并移除。
- 用户主动启用“保留临时文件”时，完成后保留缓存。删除任务与清理已完成不受此设置限制。
- 暂停、失败、取消但仍保留任务时，保留续传缓存。删除任务先停止并等待 worker，再删除本任务目录，保留下载成品；“删除任务和文件”同时删除任务记录所指向的成品。
- 清理失败会报错；删除类操作保留任务记录，以便释放文件占用后重试。已成功发布的下载不因缓存清理失败变成下载失败。
- 字幕复制失败时保留字幕源；未知文件不在完成时自动删除。手工放入任务私有目录的文件随“删除任务”一起删除。
- 不递归清空下载根目录；不遍历任务缓存中的符号链接或 Windows 重解析目录。成品位于缓存内部时拒绝直接删除该任务，避免误删成品。

## 边播边下

- 未完成任务只有实际生成可播放的预览清单后才显示“边播边下”。仅有下载字节或进入 downloading 状态不代表可播放。
- HLS 点播准备完整的本地播放清单，保留原始完整时长；首个连续分片和音轨就绪后开放入口。拖到未下载位置时，本地服务请求目标分片优先下载，并等待分片完成及解密成功的就绪标记，不向播放器返回半个文件。播放复用下载器的同一份分片。
- DASH 点播使用 MPD 展开的准确分片时间准备完整清单，并按播放器请求调整分片下载顺序；最终合并仍保持媒体时间顺序。未取得准确时间轴的表示不开放分片预览。
- 音视频分离的 HLS/DASH 当前先下载并准备独立音轨，再开放视频预览；独立音轨样例已通过实际验收，长音轨仍可能延后首次启播，未测量所有长度下的延迟。
- 普通 HTTP 媒体文件通过续传记录提供已落盘字节范围；尚未下载的范围先通知 Range 调度器提高优先级，等待落盘后再发送，不将稀疏文件中的空洞当成视频数据。只有已知总长度、已建立有效范围记录的媒体开放入口。BT 未完成文件、未知长度的 HTTP 单流、直播及 LL-HLS part 预览暂不开放。
- 完成时在原播放器内停止旧输入，并等待 `MPV_EVENT_END_FILE` 确认卸载，再按原位置、暂停状态、倍速及可恢复的音轨/字幕选择载入成品，随后清缓存。窗口不主动重建；禁用视频参数变化引起的自动窗口缩放，以黑边适配比例。六种下载样例均实际核对切换前后 HWND、PID、窗口矩形、播放位置、暂停和倍速；此过程仍有短暂重载。卸载超时则保留缓存并提示。
- 同名已存在文件不会被当成未完成任务的播放输入；改名后的成品以持久化实际路径为准。
- 播放用的完整点播清单为 VOD；合并用的本地清单独立生成。分片就绪标记、续传检查点和播放优先级文件均纳入任务清理，迟到的播放请求不会重新创建已删除的任务目录。
- 依据：[RFC 8216 §6.2.1](https://www.rfc-editor.org/rfc/rfc8216.html#section-6.2.1)、[mpv loadfile 每文件选项](https://mpv.io/manual/stable/#command-interface-loadfile)及 [mpv END_FILE 的卸载完成约定](https://github.com/mpv-player/mpv/blob/master/include/mpv/client.h)。

## 安装体积与性能实测

新包在 Windows 沙盒实际安装到含空格的自选路径，265 个安装文件共 675,107,170 字节，约 643.83 MiB；MSI 为 302,559,232 字节，约 288.54 MiB。默认保存位置实际匹配 Windows Known Folder Downloads，不使用开发机固定路径。真实 MDN 视频下载成功且与独立源请求字节一致；UI 可见并连接 Core，随后正常卸载，产品注册消失。

| 组件 | 文件大小约值 |
| --- | ---: |
| ffmpeg.exe | 157.5 MiB |
| ffprobe.exe | 157.3 MiB |
| libmpv-2.dll | 114.2 MiB |
| Java modules | 51.5 MiB |
| Material 扩展图标 JAR | 36.0 MiB |
| Presenter | 27.4 MiB |

FFmpeg、FFprobe 是分别静态链接的程序；播放器也包含解码能力。安装目录的大部分是这些运行依赖，不能直接删除 FFprobe 或播放器库来瘦身。此轮没有更换二进制依赖或改变打包方案。

磁盘文件大小不等于运行时驻留内存。8 逻辑核、禁用 GPU 的沙盒测量如下；短采样只说明该样例，不能推断所有电脑及视频的表现。RSS 合计可能重复计算共享页。

| --- | ---: | ---: | --- |
| 已安装 UI/Core/Presenter 等进程空闲 | 0.039% | 合计 222.26 MiB | 5 秒 |
| Core 下载本地限速样例 | 0.130% | 14.86 MiB | 3.016 秒 |

UI 首次可见且连接 Core 用时 11.313 秒（沙盒冷启动）。本轮修复缓存残留，未替换大型运行库或进行安装瘦身；播放解码仍会消耗 CPU/内存。
