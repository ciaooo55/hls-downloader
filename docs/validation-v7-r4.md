## 改动和证据边界

字幕预取采用最多 12 秒的内存 PCM 窗口、原速发送及真实 completed 事件确认，播放追上字幕时暂停等待；音轨变化、seek/reset 和取消会隔离旧会话。另修复 HLS 分段字幕合并、同语种轨道覆盖和桌面版本号，并修正验收脚本的运行目录、浏览器临时配置、编码、输入语义与 MSI 属性引用。

用户原网页本次 Edge 观察未加载出视频，资源列表为空，不能据此记为通过；原失败视频完整下载未验收。长视频连续云端质量、所有网站、不同电脑和硬件不在已通过证据内。真实投屏及 TVBox 按约定排除。

首次因防火墙遮挡、测试夹具或测试依赖产生的失败不计入通过；上表采用修正后实际重测结果。项目文件清理已完成：无 HLS Downloader 卸载记录或已知安装目录，Edge/Firefox 两项失效 Native Host 注册已移除；本轮临时环境、原始日志、构建依赖和旧交付备份已删除，19 个目标合计约 5.18 GiB。清理前后 420 份源码文件指纹一致，桌面四份交付包哈希一致。Brave、Chromium、Vivaldi、Opera 的四项同名失效 Native Host 注册随后由用户执行收尾脚本移除。最终通过 Windows 注册表服务 StdRegProv 独立复核 21 个浏览器注册位置及 219 条系统/用户卸载记录，未发现本项目 Native Host 或安装记录。工具进程的直接注册表读数与系统服务不一致，最终系统侧结论采用服务独立读取结果；未因此继续删除其他键。临时清理脚本、项目忽略生成文件和缺失源码清单均为空，四份桌面交付包哈希再次一致。源码修改尚未提交或同步 GitHub。不能将此记录理解为所有功能百分百无故障。
