# v7.0.3-r9 未签名预发布版

本版合并安装包精简、任务按钮与筛选交互修复，以及 HTTP 完全断流时暂停、恢复和删除迟迟不生效的修复。软件版本仍为 7.0.3，r9 用于区分交付包。安装包与插件均未签名。

## 具体修改

- 批量开始按任务状态执行开始、恢复或重试，完成任务不会重新下载；播放等单任务操作不再出现在不适用的多选或文档任务上。
- 清理已完成仅作用于当前筛选列表，并明确提示范围；取消清理保留记录，确认清理保留成品文件。搜索可清空或按 Escape 退出，空列表提供相应提示。修正禁用透明按钮的灰色背景及小窗口布局。
- Windows 管道实例暂时占满时，只在连接建立前等待，不重发已经发送的开始或删除命令。
- 直接 HTTP 响应头、正文和 chunked 读取在等待数据期间检查暂停与取消，恢复前等待旧下载进程结束，保留续传检查点。持续慢网仍保留原有 60 秒无数据预算。
- 移除生产包的 ffprobe 和全量 extended 图标库，保留实际使用的 69 个原版矢量、FFmpeg 和 libmpv，没有增加播放引擎。
- 字幕音频包的发送间隔计入 IPC 耗时，保持串行，不突发追赶积压音频。

保留此前的主窗口播放器浮层、画中画、边播边下、完整时间轴、下载完成与删除任务后的缓存清理、连续字幕响应匹配、安装路径选择和系统 Downloads 默认保存目录。

## 实际验收

- 插件类型检查、双浏览器构建和 Firefox 审核源码打包完成；381 项插件测试通过，含 11 项字幕测试。
- 桌面定向 JUnit 63 项通过，100%/150% 两档界面缩放的选择、按钮、搜索、筛选清理和小窗口场景通过。
- 沙盒 HTTP 单元测试 56 项通过。完全停发后的单连接、并行恢复约 0.234/0.250 秒，停发时删除任务及缓存约 0.218 秒；恢复成品逐字节和 SHA256 一致。
- 精简候选包通过下载/边下边播/缓存清理 21 项、播放器按钮和窗口 9 项、安装/下载/卸载 8 项及 r8 升级 4 项验收。
- 最终 r9 MSI 再次通过沙盒自选含空格路径安装、全部程序组件哈希核对、插件 ZIP 与解包文件一致、系统 Downloads 默认目录、真实 MDN 视频下载及逐字节比对、完成缓存清理、实际界面连接和卸载注册清理。

最终 MSI 为 **203,096,064 B（约 193.7 MiB）**，安装目录 **472,724,339 B（约 450.8 MiB）**。相对 r8 分别减少约 **32.9% / 30.0%**。占用主要来自 FFmpeg、libmpv 和 Java 运行时。沙盒闲置 5 秒样本中，Core 与界面等进程合计 RSS 约 245.8 MiB，占整机 CPU 约 0.195%；这不是所有电脑和负载的性能保证。

验收记录：[精简](validation-slim-20261017.json)、[界面](validation-ui-interactions-20261017.json)、[断流恢复](validation-http-stall-20261017.json)、[最终安装包](validation-r9-installer-20261017.json)。各记录保留其执行时的源码、二进制哈希和历史失败修正信息；最终安装包记录关联发布二进制。

## 验收边界

本版是未签名预发布交付，`release_ready=false`。本轮没有新增真实云端音频上传或费用；此前 r8 连续字幕云端验收记录仍保留，但字幕间隔调整没有重新测量云端延迟。直接 HTTP 的断流修复不代表 HTTPS/代理 WinHTTP 停发取消、连接建立或请求体发送也经过同样验收。原用户网站仍有访问限制，未将其标记为原片通过；投屏和 TVBox 实体设备按用户范围排除。不能据此保证所有网站、视频和电脑绝无问题。
