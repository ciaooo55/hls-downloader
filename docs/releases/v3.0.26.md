# HLS Downloader v3.0.26

投屏/TVBox 推送补上软件内可拖动悬浮窗，进度、暂停、快进快退和任务下载暂停都能直接点。同一版本修掉分片假完成、无 Range 续传，以及若干会把界面状态说错的边角。

## 投屏与推送

- 开始投屏或推送后出现可拖动悬浮窗：播放/暂停、后退/快进 10 秒、拖动进度条；播放中进度在两次状态轮询之间连续走动。
- 收起后仍是一条可点的悬浮条；状态栏芯片可重新展开。最小化条上也有对应下载的暂停/恢复。
- 投正在下载的任务时，窗内同时显示下载进度，并可暂停/恢复下载，与电视暂停分开。直播任务显示“停止录制”。
- “停止共享/停止播放”会先向 DLNA/Chromecast 发送 Stop，再撤销本机文件共享；纯 URL 投屏也会停掉电视播放。
- 状态轮询失败或 DLNA 没有可用 RelTime 时保留上次进度，不会把进度条打回 0。Chromecast 控制复用已连接会话，切换设备时会停掉上一台。
- TVBox 没有通用远程播放协议，窗上写明进度在电视端操作；URL 推送同样打开悬浮窗。本机仍可停止共享并暂停对应下载。
- 后端补齐 `status` / `seek_to` / `stop`，相对快进也支持负数。

## 下载正确性

- HLS / 原生 DASH 分片在有 `Content-Length` 时必须下满，截断不再当成功。
- HTTP 单连接暂停后按 Range 续传，不再每次从 0 重来。
- 分段下载回退单连接时会丢掉预分配的空文件；416 只有在确实写过单连接数据时才当成已经下完。
- HTTP 403 也会走浏览器 TLS 指纹回退，不再只限插件接管的任务。
- 桌面端 `download_import_route` 测试导入补齐，修复 CI cargo test。

## 界面

- 内置播放器不再因为任务暂停而拆掉 HLS；安装更新时设置窗口关不掉。
- 接管对话框开着选文件夹时 Esc 只关选择器；用户暂停桌面任务不再被当成接管失败去恢复浏览器下载；真正失败时才会放行浏览器副本。
- 空分类/搜索不再一律写“暂无任务”；任务表速度曲线暂停后不再用残留速率做 tooltip。
- 任务详情限速输入会跟随 SSE；状态栏限速芯片按本机时间即时切换分时段值。

验证覆盖相关 Python 与前端测试。协议边界不变：不绕过 DRM/EME，复杂多 Period DASH 仍可回退 yt-dlp。
