# HLS Downloader v5.0.12

5.0.11 挡住了 `?download=0` 这类观看页参数。5.0.12 按用户真的在页面上点什么来判：播放器按钮是看，文件链接才是下；当前网站常用媒体按播放器证据认，不整页扫 m3u8。

用户点到的，分别怎么走：

- 播放 / 暂停 / 下一集 / 清晰度 / 弹幕 / 全屏 / 点赞 / 分享：不记下载意图，视频继续在页内播，悬浮钮按 `currentSrc` / MSE 绑定
- 播放按钮上的 `data-url="movie.mp4"`、`<a href="movie.mp4">播放</a>`：当播放配置，不当点击下载
- `<a href="movie.mp4">` 或按钮写着「下载」：仍接管
- B 站 `/video/BV…`、优酷 `/v_show/`、腾讯 `/x/cover/`、爱奇艺 `/v_….html` 上的 `file=episode.mp4`：仍是观看页
- YouTube 一类无后缀 `/videoplayback?mime=video/mp4`：算正在播的媒体，MSE 字节能对上当前播放器；`.m4s` / `.ts` 分片仍不单独当文件
- JSON playurl 接口、图片、脚本、OAuth 仍不抢；无清单的纯分片站悬浮钮可以停在「正在识别」，不编造一个假文件

依据：`extension/lib/clickIntent.test.ts`、`extension/lib/manifestSniff.test.ts`、`extension/lib/resources.test.ts`。`extension/` 下 `pnpm test`：171 passed。

从 GitHub Release 安装 `HLSDownloader-v5.0.12-Windows-x64-Setup.exe`（或 Portable.zip），并更新浏览器扩展。
