# HLS Downloader v3.0.2

这是针对 Windows 覆盖升级失败的紧急稳定性修复。

- 覆盖安装前会先暂时注销旧版 Chrome / Edge / Firefox Native Host，避免旧浏览器插件在退出瞬间重新拉起旧桌面端和 Core。
- 安装器会强制终止旧桌面、Core 与 Native Host 进程树，并自动重试短暂的 Explorer / 安全软件文件锁；无交互更新不会停在无效的“重试”弹窗。
- 覆盖完成后自动注册当前版本的 Native Host。已有下载、任务数据库、设置、Cookie 及断点文件仍保留在安装目录外的用户数据目录。
- 桌面端、Core、Native Host 与 Chrome/Edge、两套 Firefox 插件统一为 3.0.2。
