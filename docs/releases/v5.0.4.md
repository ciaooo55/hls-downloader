# HLS Downloader v5.0.4

仔细看过 5.0.3 热路径之后，撤回两处看走眼的改动，Range 单文件 seek 语义不变。

- 去掉从未在 CI 执行过的 Windows `CreateFile` / `FILE_FLAG_RANDOM_ACCESS`。每个 worker 句柄是 seek 一次再往前写，RANDOM_ACCESS 缓存提示是反的。
- 无 Range 单连接改回随到随写（无缓冲）。5.0.3 把 256 KiB 批处理套到单连接上，崩溃时会丢掉已收到但还在内存里的前缀。
- 检查点在 `fsync` 前先 `flush`。多连接 Range 仍是线程里按 256 KiB 写；HLS/DASH 分片仍是各自文件上的 off-loop write。

从 GitHub Release 安装 `HLSDownloader-v5.0.4-Windows-x64-Setup.exe`（或 Portable.zip）。
