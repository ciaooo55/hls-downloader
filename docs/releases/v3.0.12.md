# HLS Downloader v3.0.12

这是长直播耐久性、浏览器媒体归属和大任务历史性能的稳定性更新。桌面端与浏览器插件均升级到 v3.0.12。

- HLS、DASH 和本地播放计划改用完整快照加追加 journal，长直播不再每批重写全部历史分片；支持周期压缩、损坏尾行修复和崩溃恢复。
- 修复 LL-HLS PART 被完整父分片替换后检查点重编号/恢复，以及播放计划压缩崩溃可能造成重复分片和异常时长的问题。
- DASH 直播音视频轨道可交错追加并从损坏 journal 恢复；新增分段 TTML 字幕合并和时间轴平移。
- 插件用 fetch/XHR 字节、SourceBuffer、MediaSource blob 与具体 video 建立证据链，多 MSE 播放器只在路径证据唯一时显示对应媒体，避免把广告或其他播放器误认成当前视频。
- Native Messaging 允许用户下载/确认请求抢占卡住的 ping/status，旧端口响应不会串到新请求；多浏览器短暂断连后的交互延迟更低。
- SQLite 任务历史改为批量流式读取，前端进度按任务合批更新并分批渲染任务列表，1 万任务启动峰值内存和耗时均下降。
- 扩大 CI 类型检查到 API、HLS、DASH、播放、TaskManager 等核心模块，并增加 LL-HLS、DASH、journal 崩溃恢复、活跃播放压缩和大规模状态测试。
