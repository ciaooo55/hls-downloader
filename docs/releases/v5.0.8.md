# HLS Downloader v5.0.8

5.0.7 单独塞了一个 `HLSNativeEngine.exe`（ureq + rustls），体积和进程都多余。5.0.8 把普通 HTTP GET 收进已经在跑的 `HLSNativeShell.exe --job`：还是 Range 写入同一个 `payload.downloading`，https 用系统 WinHTTP。安装时删掉那个多余 exe。

HLS / DASH / 直播 / BT 仍在 Python 核心。POST 重放、限速、浏览器 TLS 回退仍走 Python。

从 GitHub Release 安装 `HLSDownloader-v5.0.8-Windows-x64-Setup.exe`（或 Portable.zip）。
