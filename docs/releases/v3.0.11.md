# HLS Downloader v3.0.11

这是下载稳定性、直播录制、浏览器接管和覆盖升级的综合修复版本。桌面端与浏览器插件均升级到 v3.0.11。

- 修复 LL-HLS 首轮分片签名失效时过早推进序号、任务长期停在录制 0 秒的问题；清单刷新出可用签名后会继续录制。
- 支持 LL-HLS PART-only 窗口和独立 HLS 音轨同步录制，避免不完整尾段被误报为“分片缺少 URI”。
- 修复直播合并后的异常超长时间轴，并在复制封装时间轴不可信时自动回退重编码。
- HTTP 文件信息探测改用有时限的真实 GET/Range 路径，修复签名 MP4 长期停在“读取文件信息”；Range、无 Range、POST 和错误页均统一验证。
- 浏览器接管不再提前暂停原下载，使用请求链、frame、当前播放证据和稳定资源指纹减少广告/静态资源误识别；一次点击即可复用同一确认请求。
- Native Messaging 负责可信配对，后续通过短期浏览器凭据并发访问本地 Core；多浏览器和不同兼容插件版本可同时连接。
- 修复最大化权限、安装器关闭运行实例、覆盖安装、便携升级和 Native Host 文件锁竞态。
- 增加全局/单 Host 连接预算、SQLite WAL 生命周期连接、日志轮换、磁盘空间预检、下载文件 Mark-of-the-Web 和敏感 API 权限分离。
- 发布链固定 NSIS、FFmpeg 和 GitHub Actions 摘要，生成 CycloneDX SBOM，并把真实下载、扩展加载、覆盖升级和卸载 smoke 纳入发布门禁。
