# HLS Downloader v5.0.13

先把普通文件下载的接管热路径修好。zip / exe / pdf / apk 不会自动播放，不必再等播放器那套点击证据；点到文件名或附件响应就应立刻出确认窗。

具体变化：

- 主框架/子框架已经判定为文件（`.zip` 路径、`application/zip`、`filename=report.pdf`、octet-stream）时，响应头阶段就可以 offer，不再因为没点到「下载」两字而放进浏览器
- `downloads.onCreated` 对已认出的文件不再空等 450ms 文件名 + 300ms 点击；点 `ubuntu-24.04.iso` 这种文件名链接也会记意图
- `/files/`、`/dl/`、csv / vsix / nupkg / cab 按普通文件认
- 播放器按钮、观看页、自动播放 MP4 仍要点击证据，5.0.12 的边界没放宽

依据：`extension/lib/fileTakeover.test.ts`、`directResponse.test.ts`、`clickIntent.test.ts`。`extension/` 下 `pnpm test`：174 passed。

从 GitHub Release 安装 `HLSDownloader-v5.0.13-Windows-x64-Setup.exe`（或 Portable.zip），并更新浏览器扩展。
