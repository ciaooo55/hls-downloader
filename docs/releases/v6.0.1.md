# HLS Downloader v6.0.1

在 v6.0.0 切包之后补齐计划里的包装缺口：GitHub Windows 安装包始终带针定的 `libmpv-2.dll`，监视目录首次扫描只记录不导入。

具体变化：

- `scripts/build_v6.ps1` 用针定的 `7zr.exe` 从 shinchiro `mpv-dev` x86_64（非 v3）包抽出 `libmpv-2.dll` 打进 Setup / Portable；NSIS 不再 `/nonfatal`
- 便携包烟雾要求 exe 旁存在 `libmpv-2.dll`；播放仍走同进程 `LoadLibrary`，不 spawn `mpv.exe`
- 种子监视目录第一次看到某个文件夹时只 `prime()`，已有 `.torrent` / `.magnet` / `.url` 不会一次性涌进队列
- 产物名：`HLSDownloader-v6.0.1-Windows-x64-{Setup.exe,Portable.zip}`

v6.0.0 的 Setup / Portable 没有随包 libmpv。从 GitHub Release 安装 `HLSDownloader-v6.0.1-Windows-x64-Setup.exe`（或 Portable.zip）即可。
