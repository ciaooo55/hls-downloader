# HLS Downloader v1.7.1

本次更新聚焦浏览器接管的可靠性与紧凑体验。

- 默认使用来源网页（浏览器地址栏页面）的 Cookie、Referer、Origin、User-Agent 与已捕获请求头；下载源或 CDN 的精确上下文仍会按域名安全匹配，减少登录站点的 403。
- 下载确认窗口可展开“网站请求上下文”，支持按需覆盖 Cookie 与请求头；留空即沿用浏览器捕获的默认上下文。
- 修复资源选择浮层拖动失效，并让“选择资源”立即展开，不再等待下一次资源刷新。
- 确认下载窗口在折叠状态下按内容高度显示，移除重复关闭按钮；展开选项仍可滚动使用。
- Windows 上隐藏 ffmpeg/ffprobe 合并、转封装和探测时短暂出现的控制台窗口。
- GitHub REST API 被匿名限流时，更新检查会安全降级为 Release 页面版本检查；可确认新版并打开 Release 页面，不会把限流误显示成检查失败，也不会绕过安装包校验自动安装。

Firefox 插件版本：2.0.1。
