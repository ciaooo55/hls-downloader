# HLS Downloader v1.6.23

- 新增直播 HLS 录制：没有 `#EXT-X-ENDLIST` 的直播/事件清单不再提示“不支持”，而是进入录制模式，持续跟随清单增量下载分片，录制过程中即可边录边播。
- 录制结束条件完整可控：直播自然结束（收到 ENDLIST）、手动“停止录制”（原暂停按钮，停止后自动合并为 MP4）、设置中的“直播录制时长上限”（0 表示不限制）、以及源站停更自动检测（约 6 个目标时长无新分片即自动收尾），不会出现无限运行的任务。
- 录制具备崩溃恢复能力：分片元数据实时落盘（live_state.json），程序关闭或崩溃后恢复任务可继续录制，跨会话内容以时间轴间断标记衔接；直播结束后即使清单已 404，也能直接合并已录内容出片。
- 录制可靠性保护：单个分片彻底失败只跳过并标记间断，不中断整场录制，且跳过后边录边播依旧可用；合并失败或源站资源失效时保留全部已录分片供重试（包括关闭预览播放器触发的临时目录清理），绝不清空无法重新获取的直播数据。
- 录制精确性：CDN 节点回放旧清单不会被误判为"序号重置"而重复录入内容；事件型直播带大段历史清单时，录制时长上限会精确截断，不再把全部积压内容下载完才停。
- 界面适配：任务列表显示“直播录制”徽标、红点闪烁的已录制时长与 LIVE 标记；右键菜单在直播任务上显示“停止录制 / 继续录制”；设置新增录制时长上限项。
