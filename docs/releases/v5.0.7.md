# HLS Downloader v5.0.7

普通 HTTP 文件下载改走编译后的 Rust 引擎（`HLSNativeEngine.exe`）：多连接 `Range` 按偏移写入同一个 `payload.downloading`，和 IDM / AB Download Manager 同一类技术栈。HLS / DASH / 直播 / BT 仍在现有 Python 核心里。

服务器后来忽略 Range 时，原生引擎退出 30，核心丢掉稀疏文件，改单连接从头下，不会把 200 的 body 接到稀疏偏移上。POST 重放、限速、浏览器 TLS 指纹回退仍走 Python。

安装包和便携包都带 `HLSNativeEngine.exe`，和 `HLSNativeShell.exe` 放在一起。

从 GitHub Release 安装 `HLSDownloader-v5.0.7-Windows-x64-Setup.exe`（或 Portable.zip）。
