# HLS Downloader v3.0.1

这是一次稳定性修复发布，重点处理浏览器插件、桌面端 Core 生命周期与任务状态之间的竞态。

- 桌面端只在取得单实例所有权后启动 Core；后台 Native Host 唤醒不再抢焦点、置顶窗口或重复拉起 Core，减少端口冲突与下载被中断后暂停的情况。
- 浏览器连接状态改为按浏览器客户端记录。桌面端会分别显示 Edge / Chrome / Firefox 实际连接的插件版本，并明确标出需要升级的旧插件，不再相互覆盖成随机版本。
- 发送到桌面端的确认任务改为后台统一追踪：创建成功后立刻从“发送中”进入“等待确认”，连续点击多个资源可顺序处理；断连与超时会给出可重试状态。
- 删除下载任务现在是原子操作。迟到的进度、日志和完成事件不能再使已删除任务闪回、重建临时目录或保留输出文件。
- 网页视频浮层默认完全隐藏；只有正在播放且检测到关联资源时才贴近目标视频显示紧凑按钮。位置只保留在当前页面播放会话；展开面板可拖动、资源列表可滚动、关闭后回到小按钮。
- 桌面端、Core、Native Host 与 Chrome/Edge、两种 Firefox 插件统一为 3.0.1。发布继续包含 Windows 安装包、便携包、Chromium 插件与两套 Firefox 插件及源码包。
