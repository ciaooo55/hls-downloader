# HLS Downloader v1.6.10

- 修复通用任务创建接口遗漏 `request_contexts` 的问题：跨域 CDN 的 Cookie、Authorization 与播放令牌现在会被安全保存并按目标域名回放，手动 API 与批量下载和浏览器接管保持一致。
- 浏览器插件与桌面 HTTP 下载器统一增强 `Content-Disposition` 文件名解析：支持 RFC 5987 UTF-8、ISO-8859-1 文件名，以及带分号的带引号名称，避免国际化下载名称乱码或截断。
- 保持既有的播放器悬浮下载、精确点击接管、HLS/DASH/BT 和两套完整 Firefox 插件功能。
