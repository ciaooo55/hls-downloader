# HLS Downloader v5.0.2

对照 IDM / AB Download Manager 的技术栈、下载引擎和文件拼接之后，这一版只改 HTTP 落盘热路径，不换语言、不把 HLS 当字节拼接。

- HTTP 仍是单个 `payload.downloading`：Range 多连接 `seek` 写入，发布时重命名，不是 `part1+part2` 拼接。
- NTFS 预分配改为稀疏文件（`FSCTL_SET_SPARSE`），避免大文件一开始就物理填零。
- 每个 Range 分片在重试和 CDN 截短的 206 循环里只开一次文件句柄。
- HLS/DASH 不变：MPEG-TS 走 `concatf`；fMP4 走本地 ENDLIST 清单 + FFmpeg 时间轴。
- 对照说明见 `docs/engine-stack.md`。

从 GitHub Release 安装 `HLSDownloader-v5.0.2-Windows-x64-Setup.exe`（或 Portable.zip）。
