# HLS Downloader v5.0.10

IDM 快，是因为托盘进程已经在、窗口已经建好、点一下只 Show。ABDM 的优点是原生界面 + 单文件 Range 写入。本项目的 HLS/DASH/BT/接管仍留在 Python 核心，不拿功能换体积。

5.0.10 把空闲热路径从「先开 Tauri/WebView2」改成「先开 `HLSNativeShell.exe`」：

- 开始菜单 / 桌面快捷方式 / 安装完成运行 → `HLSNativeShell.exe`
- 监督进程自己拉 `HLSDownloaderCore.exe`，自己托盘，任务列表是已有的原生窗
- `frontend/src-tauri/tauri.conf.json` 启动时 **不再创建任何 WebView 窗口**；设置 / 新建 / 播放器才启动 `HLSDownloader.exe --settings`
- 普通 HTTP GET 仍在这份常驻进程里 Range 写入（5.0.9）

没有测过、所以不写进验收的：总内存小于 IDM（Python + FFmpeg + libtorrent 还在）；设置页打开后的 WebView2 工作集。

从 GitHub Release 安装 `HLSDownloader-v5.0.10-Windows-x64-Setup.exe`（或 Portable.zip）。
