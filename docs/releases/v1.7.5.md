# HLS Downloader v1.7.5

- 浏览器扩展现在始终将标签页地址栏的顶层页面作为来源页；iframe/CDN 媒体不会再把自身地址误作来源网页。
- 资源接管会保留所选媒体请求的按来源隔离上下文，包括实际捕获的 Cookie、Authorization 与站点专用请求头；不会把凭据复制到其他域名。
- 手动新建下载的“请求上下文”支持来源网页 URL、一键填入可编辑的 Referer / Origin、Cookie、User-Agent 和任意附加请求头。识别、清晰度探测和正式下载使用同一组手工上下文。
- 移除了任何站点固定预填；所有来源页面与请求头都按当前网页或用户输入处理。
- 视频“选择资源”浮标使用窗口级拖拽捕获，播放器刷新或指针移出按钮时也不会中断拖动。
- 浏览器下载确认窗初始尺寸缩小为内容尺寸；展开保存或请求上下文时会按内容调整，超出屏幕时使用窗口内滚动。

Firefox 插件版本：2.0.5。
