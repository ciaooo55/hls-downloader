# HLS Downloader v3.0.27

v3.0.26 发布后再修一轮会直接踩到的边角：共享过期不停电视、指纹回退长度校验、未信任分片被当成续传，以及播放器把断网说成编码问题。

## 投屏

- 本机文件共享空闲过期时，会先向电视发 Stop，再清掉悬浮窗。
- 没有总时长时进度钟不再往前空跑；快进快退在控制忙时会排队，跳转后有提示。

## 下载

- 浏览器 TLS 指纹回退强制 identity 编码，压缩响应不再拿 Content-Length 当本地文件长度。
- 指纹回退支持按顺序水印续传，暂停不再每次从 0 重来。
- 没有顺序水印的半成品分片会被丢掉，避免 206 接到全零预分配文件上。
- 已有可信单连接前缀时，即使探测到 Range 也不会再截成稀疏分段文件。
- `Content-Range: bytes X-Y/*` 续传会保留已知总大小。

## 其它

- 接管后续清理成功后会重新显示浏览器下载栏；桌面任务仍在等待时会继续跟，而不是丢掉跟踪。
- 内置播放器在已下载前缀内的跳转不再拆 HLS；网络错误不再误报成编码不支持。
