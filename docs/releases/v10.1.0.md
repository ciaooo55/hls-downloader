# HLS Downloader 10.1.0（发布草案）

> 当前为 **10.1.0** 发布草案（尚未发布正式安装包）；当前最新稳定版为 [10.0.0](v10.0.0.md)。

10.1.0 在 10.0.0 纯原生 Rust Core + Slint 架构基础上，完成了桌面工作台与 Manifest V3 浏览器扩展的旗舰级视觉与交互重塑，带来普通 HTTP `GET` 直连多线程接管加速、原生 `WinHTTP` 优先分片拉取、默认 HLS `.ts -> .mp4` 与双轨 `.m4s` 无损混流封装、过期签名链接刷新续传、原生 FTP/SFTP 代理隧道，以及底层异步 IPC、Win32 进程生命周期与全量生产代码安全契约的系统性升级。

## 主要变化

### 桌面工作台与弹窗重塑（Slint UI）
- **Fluent Graphite + Luminous Cobalt 设计体系与原生字体渲染**：全面升级主工作台、新建/批量任务编辑器、确认窗、双模式进度 HUD（完整详情视图 / 紧凑迷你条）、完成提示窗、设置中心与内置播放器的深浅双主题视觉层次；全面切换至 Windows 原生多字重 `Microsoft YaHei UI` 字体排版，兼顾 Regular / Bold 锐利显示并缩减约 16.4 MB 二进制体积。
- **右侧非模态任务检视抽屉**：支持快捷键 `Alt+I` 或工具栏一键展开/收起右侧内联检视面板，实时查看速度曲线、`SegmentMapBar` 分片落盘状态图、连接数汇总与传输诊断，无需频繁开关独立模态窗。
- **窗口生命周期与细节交互打磨**：统一二级对话框系统原生标题栏样式，彻底消除启动阶段的幽灵弹窗竞态（ghost-popup race）；完成提示窗（`CompleteWindow`）支持 10 秒鼠标悬停感知自动关闭（悬停时暂停计时），首次关闭主窗口至托盘时弹出一次性原生气泡提示，任务表格配备可拖拽交互滚动条，设置中心（`SettingsWindow`）常用布尔开关支持即时自动保存（Live-Save）。
- **高频效率交互**：新增全局快捷键（`Ctrl+F` 搜索、`Ctrl+,` 设置、`Alt+I` 右侧检视抽屉、`Space` 暂停/恢复选中任务）、通配符批量 URL 生成、工具栏一键限速胶囊、现代 COM 目录选择器、剪贴板链接智能识别，以及不抢占前台焦点的顺滑弹窗呈现。

### 浏览器扩展（MV3）与直连多线程接管
- **HTTP `GET` 直连多线程接管加速**：普通 HTTP/HTTPS `GET` 文件下载、HLS（`.m3u8`）、DASH（`.mpd`）及分离音视频流直接通过 Native Messaging 移交桌面 Rust Core 执行多连接分段加速；一次性 `POST` 表单与 `Blob` / `data:` 生成文件保留浏览器原响应完成后安全导入，避免重复请求。
- **一键站点 Cookie 授权与静默快下**：新增一键 `[授权本站]` Cookie 授权横幅（按站点显式授权后随交接透传 Cookie）与弹窗常驻快捷设置栏；支持在扩展与桌面端同步开启“静默快速下载”（Core 端自动接收免弹窗入队），按住 `Alt` 点击链接、关闭自动接管或命中排除规则时原样保留浏览器下载。
- **流媒体精准嗅探、DRM 识别与悬浮交互**：重构扩展弹窗与页面链接批量面板（支持关键词搜索、全部/流媒体/视频/音频/文件分类筛选、一键批量下载），新增网页视频悬停一键画质胶囊并端到端透传 `preferred_variant_id`；新增 Bilibili 番剧/影视 `/ogv/player/playview` 接口解析、YouTube MSE 分片噪声过滤，以及 Widevine / PlayReady / SAMPLE-AES 受保护 DRM 流检测提示（明确提示受保护状态，不作破解绕过）。

### 流媒体合流、WinHTTP 引擎、签名续传与多协议代理
- **默认无损 `.mp4` 重封装与双轨合流**：默认开启点播 HLS `.ts -> .mp4` 无损重封装并支持 FLAC-in-MP4 音频封装（正确保留无独立 `URI` 的 `DEFAULT=YES` 内嵌原声轨道，不被外部副音轨覆盖）；新增 `audio_url` 双轨并发下载与 FFmpeg 无损 `.mp4` 混流管线（原生支持 Bilibili 等站点的分离视频 `.m4s` + 音频 `.m4s` 自动合流，单轨报错时完整保全已下载轨道与断点状态）及合成阶段状态展示；保留 `.kmz`、`.3mf` 等合法非危险 ZIP 容器文件扩展名。
- **原生 `WinHTTP` 优先分片拉取与 WAF 回退**：Core 分片传输优先采用 Windows 原生 `WinHTTP` 高效拉取，遇到站点指纹校验或 WAF 403 拦截时自动无缝回退至 `curl-impersonate` 并支持缓存恢复；DASH 点播对齐批量检查点刷盘策略（32 分片 / 64 MiB / 1 秒）。
- **过期签名 URL 刷新续传**：支持保留已落盘分片与字节检查点刷新过期签名链接后无缝续传，新增带来源/资源身份匹配保护的浏览器辅助刷新入口（`ArmTaskRefresh`，防止等待期内误劫持无关标签页下载）与轮换 CDN 签名链接的归一化去重识别。
- **原生 FTP/FTPS 与 SFTP 代理隧道**：控制连接、被动数据连接及 `russh` SFTP 会话全面支持 HTTP CONNECT（Basic 认证）、SOCKS5/5h（用户名密码）、SOCKS4/4a 与 Windows WinINet 按 URL 系统代理路由；代理握手或鉴权失败严格 fail-closed，杜绝直连泄露。

### Rust Core 性能、进程卫生与全栈安全加固
- **零轮询异步 IPC 与按需冷启动唤醒**：以 Win32 Overlapped Named Pipe I/O 替代轮询等待，消除空闲状态下的周期写盘开销；后台收到浏览器交接或需交互事件时支持冷启动唤醒 Presenter，而在用户从托盘主动退出后持久化停机标记，避免浏览器静默探测意外唤醒引擎。
- **Win32 Job Object 进程卫生**：通过 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` 统一托管 FFmpeg、`curl-impersonate` 等外部子进程生命周期，确保主引擎退出或异常终止时不残留孤儿进程。
- **生产代码安全契约与防崩溃审计**：生产 Crate 全面启用 `#![cfg_attr(not(test), warn(clippy::undocumented_unsafe_blocks))]` 门禁，完成全仓生产 `unsafe` 块与 `unsafe impl` 的 `// SAFETY:` 不变量核查注释，并清理生产代码路径中的未受保护 `.unwrap()`；代理凭据统一纳入 Windows DPAPI 加密保险库与日志脱敏，强化自动更新签名器单源校验、MSI 安装器进程协调及 SSRF / 跨域重定向安全边界。

## 从 10.0.0 升级

- **10.0.0 → 10.1.0**：EXE / MSI 安装包保持原有升级身份原地覆盖升级，继续使用 `%LOCALAPPDATA%\HLS Downloader\v7` 数据目录，完整保留已有任务、设置、队列与 DPAPI 加密凭据；Portable 便携版通过内置升级脚本更新程序文件并保留 `data/` 目录。
- **早期 5.x / 7.x 版本**：7.x 可直接原地升级；5.x（旧版 Tauri/Python）请先备份已下载文件后参考 [10.0.0 发布说明](v10.0.0.md) 全新安装。

Windows x64 安装包暂未代码签名，更新需手动安装。Chrome / Edge 使用配套 Chromium 扩展；Firefox 提供待签名包与构建源码，在标准版 Firefox 中永久安装仍需 Mozilla 签名。

## English summary

10.1.0 (release draft) builds on the native 10.0.0 Rust Core + Slint architecture with major upgrades across the desktop workbench, MV3 extensions, streaming muxer, and core engine:

- **Flagship Slint UI, native typography & window ergonomics**: refreshed **Fluent Graphite + Luminous Cobalt** Light/Dark/System themes, native multi-weight `Microsoft YaHei UI` typography (~16.4 MB binary reduction with crisp Regular + Bold rendering), a non-modal right-side Task Inspector Drawer (`Alt+I`) with live speed curves and `SegmentMapBar`, unified native captions on secondary dialogs, startup ghost-popup race elimination, 10s hover-aware `CompleteWindow` auto-dismiss, one-time close-to-tray native balloon hint, interactive task-table scrollbar, instant live-save for everyday boolean toggles in `SettingsWindow`, dual-mode progress HUDs, wildcard batch URLs, global speed-limit pill, and keyboard shortcuts (`Ctrl+F`, `Ctrl+,`, `Alt+I`, `Space`).
- **MV3 extension acceleration & media intelligence**: direct HTTP/HTTPS `GET` multi-connection takeover acceleration via Native Messaging alongside HLS (`.m3u8`), DASH (`.mpd`), and split video+audio streams (preserving one-time `POST` and `Blob`/`data:` responses safely in-browser before import); 1-click `[授权本站]` per-host Cookie auth banner, always-visible quick-settings bar, 1-click silent quick download, `Alt`-click bypass, Widevine/PlayReady/SAMPLE-AES DRM detection, Bilibili `/ogv/player/playview` support, YouTube MSE slice filtering, redesigned popup search/category filters, and on-video hover quality pills with exact `preferred_variant_id` selection.
- **WinHTTP-first fetching, lossless muxing, presigned URL resume & proxy tunneling**: native `WinHTTP`-first segment fetching with automatic `curl-impersonate` WAF fallback, default lossless HLS `.ts -> .mp4` remuxing + FLAC-in-MP4 support, concurrent dual-track video+audio (`audio_url`, e.g. Bilibili `.m4s`) download with lossless FFmpeg `.mp4` muxing, Core-side quick-download auto-accept, checkpoint-preserving presigned URL refresh (`ArmTaskRefresh`) & rotating CDN duplicate detection, and fail-closed HTTP CONNECT / SOCKS5 / SOCKS4 / WinINet proxy tunneling for native FTP/FTPS and `russh` SFTP.
- **Core efficiency, Win32 Job Object hygiene & production safety audit**: overlapped Win32 Named Pipe IPC, zero-idle store writes, cold-start Presenter wakeup on background events with tray user-shutdown persistence, Win32 Job Object (`KILL_ON_JOB_CLOSE`) lifecycle management for FFmpeg/`curl-impersonate` child processes, DPAPI proxy credential vaulting, SSRF/redirect boundary hardening, and a production-wide `unsafe` audit (`#![cfg_attr(not(test), warn(clippy::undocumented_unsafe_blocks))]` with explicit `// SAFETY:` invariants) alongside production `.unwrap()` elimination.

10.0.0 → 10.1.0 upgrades cleanly in place while preserving `%LOCALAPPDATA%\HLS Downloader\v7` tasks, settings, and encrypted credentials.
