# HLS Downloader 10.1.0（发布草案）

> 当前为 **10.1.0** 发布准备草案，尚未完成正式打包验收与发布；最新已发布正式版仍为 [10.0.0](v10.0.0.md)。正式成品、同源检查与文件哈希以后续发布附件 `ARTIFACT-MANIFEST.json` 和 `RELEASE-EVIDENCE.json` 为准。

10.1.0 在 10.0.0 纯原生 Rust Core + Slint 架构基础上，完成了桌面工作台与浏览器扩展的统一视觉与效率升级、原生 FTP/SFTP 代理隧道与精确变体选择等核心能力补齐，以及六轮覆盖全栈的安全与可靠性加固。

## 主要变化

### 桌面工作台与浏览器扩展升级
- **#132**：基于 **Fluent Graphite + Luminous Cobalt** 深浅双主题全面打磨 Native Slint UI（工作台、确认/进度/完成弹窗、任务详情、队列、设置、站点规则与媒体播放器）与浏览器扩展（弹窗、悬浮下载按钮、视频悬停浮层与字幕浮层），并通过全部 WCAG 对比度审计。
- **#132**：工作台新增**非模态可折叠底部任务检视抽屉**（实时速度曲线、`SegmentMapBar` 分片状态、连接汇总与诊断）、新增效率快捷键（`Ctrl+F` 搜索、`Ctrl+,` 设置、`Alt+I` 展开/收起检视抽屉、`Space` 暂停/恢复选中任务），任务编辑器将非常用参数收敛为可折叠「高级选项」。
- **#132**：浏览器扩展弹窗新增资源关键词搜索、动态分类筛选胶囊（全部 / 流媒体 / 视频 / 音频 / 文件）与筛选结果一键批量下载，并将用户在弹窗选中的精确画质变体（`preferred_variant_id`）透传至桌面端。
- **#124 / #125**：优化 Windows 工作台响应速度、动效反馈、本地播放、通知和 Core 错误接线。

### 核心传输与流媒体引擎增强
- **#133**：原生 FTP/FTPS（控制连接、被动数据连接与分段连接）和原生 `russh` SFTP 会话全面支持代理隧道：HTTP CONNECT（Basic 认证）、SOCKS5 / SOCKS5h（用户名密码认证）、SOCKS4 / SOCKS4a（用户标识）及 Windows WinINet 按 URL 系统代理路由；代理模式下自动禁用主动 FTP 与外部 OpenSSH CLI 回退，认证/握手失败或遇到不支持的 `https://` 代理 / SOCKS4 密码时严格 fail-closed，确保零直连泄露。
- **#133**：`preferred_variant_id` 贯通协议契约、Native Host、任务持久化、去重与下载器：HLS 支持签名轮换后的归一化路径精确匹配，DASH 支持按 Representation ID 或明确媒体 URL 精确选择，兼容旧任务数据反序列化。
- **#133**：DASH 点播音视频分片落盘改为按 32 分片 / 64 MiB / 1 秒批量 `sync_data` 与检查点持久化，与 HLS 点播策略对齐；暂停、取消、异常和完成均正确刷盘，未同步批次在恢复时自动重下。

### 安全与稳定性加固
- **#123**：移除 10.x 之前遗留的兼容路径与过期依赖。
- **#126–#131**：完成六轮多维度全栈审计与加固，覆盖代理凭据 DPAPI 保险库托管与日志脱敏、更新包签名信任链单源校验与 MSI 安装器加固、SSRF 与重定向边界防护、Core 调度器与 SQLite 事务、浏览器接管回执与队列状态机、媒体/投屏/BT 传输引擎及本地 E2E 冒烟回归。

## 从 10.0.0 升级

- **10.0.0 → 10.1.0**：MSI 采用原安装与升级身份原地覆盖升级，沿用 `%LOCALAPPDATA%\HLS Downloader\v7` 数据目录和 schema 7，保留任务、设置和 DPAPI 加密凭据；便携包按便携升级流程替换程序目录，不覆盖用户数据。
- **10 之前的版本（5.x / 7.x）**：请先备份配置、任务库和下载文件，参考 [10.0.0 发布说明](v10.0.0.md) 进行升级或全新安装。

Windows x64 安装包未签名，更新需手动安装。Chrome / Edge 使用配套 Chromium 扩展；Firefox 提供待签名包和源码，标准版永久安装仍需 Mozilla 签名。

## English summary

10.1.0 (release draft, pending formal Windows x64 packaged acceptance) builds on the clean 10.0.0 Rust Core + Slint foundation with:
- **Fluent Graphite + Luminous Cobalt UI & extension polish (#124, #125, #132)**: unified Light/Dark visual refresh across the Slint workbench, presenter popups, player, and browser extension; non-modal collapsible bottom Task Inspector Drawer (`Alt+I`), keyboard shortcuts (`Ctrl+F`, `Ctrl+,`, `Alt+I`, `Space`), collapsible advanced options in the task editor, and popup search/category filtering with one-click batch download.
- **Core transfer & streaming upgrades (#133)**: fail-closed proxy tunneling (HTTP CONNECT Basic, SOCKS5/5h auth, SOCKS4/4a, Windows WinINet per-URL routing) for native FTP/FTPS and `russh` SFTP; end-to-end exact HLS/DASH variant selection (`preferred_variant_id`); and batched DASH VOD segment checkpoint syncing (32 segments / 64 MiB / 1 s).
- **Six-round full-stack hardening (#123, #126–#131)**: removal of pre-10 compatibility paths, DPAPI vaulting for proxy credentials, single-source updater signer verification, SSRF/redirect boundary hardening, and Core/UI/extension reliability fixes.

10.0.0 → 10.1.0 upgrades in place while preserving `%LOCALAPPDATA%\HLS Downloader\v7`, tasks, settings, and encrypted credentials. Formal artifact hashes and Windows acceptance evidence will be attached upon formal release.
