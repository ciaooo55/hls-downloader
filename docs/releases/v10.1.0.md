# HLS Downloader 10.1.0（发布草案）

> 当前为 **10.1.0** 发布草案（尚未发布正式安装包）；当前最新稳定版为 [10.0.0](v10.0.0.md)。

10.1.0 在 10.0.0 纯原生 Rust Core + Slint 架构基础上，完成了桌面工作台与 Manifest V3 浏览器扩展的旗舰级视觉与交互重塑，带来普通 HTTP 直连多线程接管、过期签名链接刷新续传、双轨 `.m4s` 与 HLS 无损 `.mp4` 自动混流封装、原生 FTP/SFTP 代理隧道，以及底层 IPC 与 Win32 进程生命周期的系统性升级。

## 主要变化

### 桌面工作台与弹窗重塑（Slint UI）
- **Fluent Graphite + Luminous Cobalt 设计体系**：全面升级主工作台、新建/批量任务编辑器、确认窗、双模式进度 HUD（完整详情视图 / 紧凑迷你条）、完成提示窗、设置中心与内置播放器的深浅双主题视觉层次及对比度表现。
- **非模态底部任务检视抽屉**：支持快捷键 `Alt+I` 展开/收起内联检视面板，实时查看速度曲线、`SegmentMapBar` 分片落盘状态图、连接数汇总与传输诊断，无需频繁开关独立模态窗。
- **高频效率交互**：新增全局快捷键（`Ctrl+F` 搜索、`Ctrl+,` 设置、`Alt+I` 检视抽屉、`Space` 暂停/恢复选中任务）、通配符批量 URL 生成、工具栏一键限速胶囊、现代 COM 目录选择器、剪贴板链接智能识别，以及不抢占前台焦点的弹窗与顺滑窗口呈现体验。

### 浏览器扩展（MV3）与直连多线程接管
- **HTTP 直连多线程接管加速**：普通 HTTP/HTTPS 文件下载、HLS（`.m3u8`）、DASH（`.mpd`）及分离音视频流直接通过 Native Messaging 移交桌面 Rust Core 执行多线程分段加速；一次性 `POST` 表单与 `Blob` / `data:` 生成文件保留浏览器原响应完成后安全导入，避免重复请求。
- **静默快速下载与无感绕过**：支持在扩展弹窗与桌面端同步开启“静默快速下载”跳过确认弹窗一键入队；按住 `Alt` 点击链接、关闭自动接管或命中排除规则时原样保留浏览器下载。
- **全新扩展弹窗与网页浮层**：重构扩展工具栏弹窗与页面链接批量面板（支持关键词搜索、全部/流媒体/视频/音频/文件分类筛选、一键批量下载），新增网页视频悬停一键画质选择胶囊，并将所选精确变体（`preferred_variant_id`）端到端透传至桌面下载器。

### 流媒体合流、签名续传与多协议代理增强
- **双轨音视频下载与 FFmpeg 无损封装**：新增 `audio_url` 双轨并发下载与混流管线，原生支持 Bilibili 等站点的分离视频 `.m4s` + 音频 `.m4s` 自动无损封装为 `.mp4`，并完善 HLS 点播无损 `.mp4` 封装与合成阶段状态展示。
- **过期签名 URL 刷新续传**：支持保留已落盘分片与字节检查点刷新过期签名链接后无缝续传，新增浏览器辅助刷新入口（`ArmTaskRefresh`）与轮换 CDN 签名链接的归一化去重识别。
- **原生 FTP/FTPS 与 SFTP 代理隧道**：控制连接、被动数据连接及 `russh` SFTP 会话全面支持 HTTP CONNECT（Basic 认证）、SOCKS5/5h（用户名密码）、SOCKS4/4a 与 Windows WinINet 按 URL 系统代理路由；代理握手或鉴权失败严格 fail-closed，杜绝直连泄露。
- **DASH 与 HTTP 吞吐优化**：DASH 点播对齐批量检查点刷盘策略（32 分片 / 64 MiB / 1 秒），并优化 HTTP/DASH 分片并发调度与 WAF `curl-impersonate` 403 回退恢复。

### Rust Core 性能、进程卫生与安全加固
- **零轮询异步 IPC 与低功耗空闲态**：以 Win32 Overlapped Named Pipe I/O 替代轮询等待，消除空闲状态下的周期写盘开销；托盘主动退出后记录停机标记，避免浏览器后台静默探测意外唤醒引擎。
- **Win32 Job Object 进程卫生**：通过 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` 统一托管 FFmpeg、`curl-impersonate` 等外部子进程生命周期，确保主引擎退出或异常终止时不残留孤儿进程。
- **全栈安全加固**：代理凭据统一纳入 Windows DPAPI 加密保险库并做日志脱敏，强化自动更新签名器单源校验、MSI 安装器进程协调以及 SSRF / 跨域重定向安全边界。

## 从 10.0.0 升级

- **10.0.0 → 10.1.0**：EXE / MSI 安装包保持原有升级身份原地覆盖升级，继续使用 `%LOCALAPPDATA%\HLS Downloader\v7` 数据目录，完整保留已有任务、设置、队列与 DPAPI 加密凭据；Portable 便携版通过内置升级脚本更新程序文件并保留 `data/` 目录。
- **早期 5.x / 7.x 版本**：7.x 可直接原地升级；5.x（旧版 Tauri/Python）请先备份已下载文件后参考 [10.0.0 发布说明](v10.0.0.md) 全新安装。

Windows x64 安装包暂未代码签名，更新需手动安装。Chrome / Edge 使用配套 Chromium 扩展；Firefox 提供待签名包与构建源码，在标准版 Firefox 中永久安装仍需 Mozilla 签名。

## English summary

10.1.0 (release draft) builds on the native 10.0.0 Rust Core + Slint architecture with major upgrades across the desktop workbench, MV3 extensions, streaming muxer, and core engine:

- **Flagship Slint UI overhaul**: refreshed **Fluent Graphite + Luminous Cobalt** Light/Dark/System themes, a non-modal collapsible bottom Task Inspector Drawer (`Alt+I`) with live speed curves and `SegmentMapBar`, dual-mode compact/detailed progress HUDs, wildcard batch URLs, global speed-limit pill, keyboard shortcuts (`Ctrl+F`, `Ctrl+,`, `Alt+I`, `Space`), and non-activating popup ergonomics.
- **MV3 extension & direct HTTP takeover**: direct Native Messaging handoff of ordinary HTTP/HTTPS downloads, HLS (`.m3u8`), DASH (`.mpd`), and split video+audio streams to the Rust Core for multi-connection acceleration; safe browser-side payload preservation for one-time `POST` and `Blob`/`data:` downloads; 1-click silent quick download, `Alt`-click bypass, redesigned popup search/category filters, and on-video hover quality pills with exact `preferred_variant_id` selection.
- **Dual-track muxing, presigned URL resume & proxy tunneling**: concurrent video+audio (`audio_url`, e.g. Bilibili `.m4s`) download with lossless FFmpeg `.mp4` muxing, HLS `.mp4` remuxing, checkpoint-preserving presigned URL refresh & browser-assisted `ArmTaskRefresh`, rotating CDN duplicate detection, and fail-closed HTTP CONNECT / SOCKS5 / SOCKS4 / WinINet proxy tunneling for native FTP/FTPS and `russh` SFTP.
- **Core efficiency, Win32 Job Object hygiene & security**: overlapped Win32 Named Pipe IPC, zero-idle store writes, tray user-shutdown persistence, Win32 Job Object (`KILL_ON_JOB_CLOSE`) lifecycle management for FFmpeg/`curl-impersonate` child processes, DPAPI proxy credential vaulting, and SSRF/redirect boundary hardening.

10.0.0 → 10.1.0 upgrades cleanly in place while preserving `%LOCALAPPDATA%\HLS Downloader\v7` tasks, settings, and encrypted credentials.
