# HLS Downloader v3.0.25

修掉审查里确认会丢文件、升不了库、或把设置打崩的问题，并补上接管等待和电源动作的并发边角。同一版本也带上已完成的下载管理器能力：FTP/SFTP、镜像、Metalink、站点规则和完成扫描等。

## 可靠性

- Firefox 不再在确认窗弹出时 `cancel` 浏览器响应；拒绝/过期后由 `downloads.onCreated` 恢复原下载，与 Chromium 暂停-再决定对齐。
- 设置页自定义杀毒命令说明里的 `{file}` 改为字面量，打开「通用」不再 `ReferenceError`；分类目录 placeholder 和系统代理文案一并改准。
- 已有数据库即使 `schema_migrations` 停在 version=1，也会补上 `speed_limit_kib` / 选轨列，并升到 version=2。
- `build_task_headers` 在同 origin 的空 scoped cookie 上回退顶层 Cookie，与确认窗 `effective_context` 一致，跨 origin 仍不泄漏。
- HTTP 分段网络数据随到随收、本地攒 256KB 再写（断线时先刷已收字节再按 Range 续传），checkpoint 改为 5 秒一次 fsync；DASH yt-dlp 回退的进度回调回到事件循环线程。
- `wait_handoff` 在 `accepting` 期间继续等终态；`/browser/downloads` 走 `claim` / `complete_accept`；电源「立即执行」与倒计时不会各跑一次。
- 任务详情暂停后速度/ETA 显示 `--`；更新安装中点遮罩不再关掉对话框；播放器失败后不再对已停止任务无限 `startLoad`，全屏 Esc 先退出全屏。

## 下载管理器

- FTP/FTPS、SFTP 单连接续传；HTTP 备用镜像、Metalink、页面抓取与链接文件导入。
- 站点规则、分类目录、分时段限速、完成提示音、可选杀毒扫描、失败自动重试和启动续传。
- 连接图、速度曲线、队列拖拽排序；重复任务可选择继续已有项。

验证覆盖相关 Python 与前端/扩展测试。协议边界不变。
