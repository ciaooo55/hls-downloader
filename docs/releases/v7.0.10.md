# HLS Downloader 7.0.10

- 普通新建入口的 BT 多文件种子现在按原目录结构交付，默认下载全部文件。只包含一个条目的多文件种子也保留目录结构。交付使用实际传输的元数据，进入交付后停止接受文件选择变更，并检查所选数据完整性。
- BT 目录在全部文件写入并同步后整体发布；同名目录另取名称或按 skip 策略拒绝，保留已有目录和文件。
- 磁力链接支持只有 xs 元数据地址的入口；带有 info hash 时校验元数据身份，再采用其中的文件布局。
- 安装器支持核验并安全停止同一安装目录的多个 Core，包括使用私有管道的新 Core。停机等待下载检查点，拒绝或超时会中止安装；其他安装目录的进程继续运行。
- 托盘退出先停止活动传输并保存断点。保存失败时保留 Core 和托盘，提示稍后重试。
- EXE 安装器正确采用选择的自定义目录，支持中文路径。
- 修正媒体代理的重复 socket 句柄问题，并兼容不支持 extension_picky 选项的 FFmpeg 构建。

Windows x64 安装包未签名，更新需手动安装。Chrome／Edge 使用配套 Chromium 扩展；Firefox 提供待签名包和源码，标准版永久安装仍需 Mozilla 签名。

投屏／TVBox 接收端、真实云端字幕质量与延迟、物理多显示器和高 DPI 切换未计入本轮实机验收。具体成品、同源检查和文件哈希以发布附件为准；不宣称完成 IDM 同条件性能对照。
