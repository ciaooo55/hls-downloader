# HLS Downloader v3.0.8

## 稳定性修复

- 安装覆盖升级只执行一次有界关闭流程；保存可续传任务后关闭桌面端与 Core，总等待不再按阶段重复叠加，浏览器持有的版本化 Native Host 不会阻塞覆盖安装。
- HTTP 文件探测使用有界小范围 GET，并修复流式 403 诊断与任务删除后的孤立检查点协程，失败任务不会长期停在“准备下载”。
- HTTP Range 增加响应范围、实体版本和落盘检查点校验，支持精确续传、动态分片以及服务器降级时的安全回退。
- 修复任务刚显示“已暂停”时立即继续会误报“任务已经在运行”的收尾竞态。
- LL-HLS 支持独立音视频长期录制与最终合并，忽略未完成 `EXT-X-PART` 尾项，并移除不可复用的阻塞轮询游标。
- HLS/DASH/HTTP 在 429、503 时共享服务端冷却窗口，避免多个工作线程同时重试放大限流。

## 浏览器插件

- 直播下载会从同一标签页选择最近一次成功的清单请求并使用其最新短效签名，明确排除已返回 403 的轮询地址。
- 精确归属到单个播放器的资源可直接一键发送；多播放器或 MSE 归属不明确时仍保留选择面板，避免误下载。
- 发送中、等待确认和已加入状态跨直播页面重绘保持，连续点击不会创建重复任务。
- Native Messaging 短暂断开时自动重连并安全重试一次；请求带幂等标识，HTTP 与 Native 双通道切换也只创建一个确认任务。
- 请求历史有界保存，失败请求立即清理，支持多个浏览器、不同插件版本同时连接。
- 插件心跳同步桌面端推荐版本并在弹窗中提示更新；商店安装继续使用浏览器自动更新，开发者模式安装提供新版发布页和重新加载说明。

## 边下边播

- 播放器首次只加载已经完整落盘的连续本地分片，避免为了尚未下载的未来分片等待 45 秒。
- 普通回看直接在本地跳转；只有用户明确拖到未下载位置时才切换到稀疏清单并优先下载目标分片。
- HLS/DASH 输出发布与 HTTP/HLS/DASH 强制落盘检查点移到工作线程，保留原子恢复安全性的同时避免慢磁盘或杀毒扫描卡住界面/API。

## 协议、字幕与调度

- HLS 直播外挂字幕会随滑动窗口持续缓存；AES-128 WebVTT 可解密，直播停止或异常收尾后仍会输出 `.vtt/.srt`。
- DASH 新增 WebVTT、TTML 与 `wvtt/stpp` fMP4 字幕保存；字幕失败保持 best-effort，不会破坏已验证的视频结果。
- 新任务支持计划开始、计划停止和完成后关机、睡眠或休眠；全局队列支持星期规则、自动停止和跨午夜时间窗，Core 重启后继续生效。
- 电源动作默认提供 30 秒可取消倒计时，也可立即执行；退出 Core 会取消尚未执行的动作。

## 安全与资源治理

- 修复 `/ui` 路径穿越并收紧扩展 CORS；浏览器接管入口使用严格模型、字段上限和 256 KiB 请求体限制。
- Cookie、授权头、代理凭据、站点配置和含签名的任务 URL 使用 Windows DPAPI 静态保护，设置接口只返回掩码状态。
- 代理绕过和 Host 规则对重定向与后续清单 URL 逐跳重新判断；增加全局及单 Host 连接预算和共享退避。
- SQLite 使用生命周期内 WAL 连接；进度事件节流，任务日志异步轮换，浏览器历史与嗅探缓存均有容量和过期上限。

## 更新、安装与维护

- 安装器在 32 位 NSIS 中通过 Sysnative 调用 64 位 PowerShell，并使用 CIM 路径回退，可靠识别和关闭 64 位桌面/Core 后再覆盖或卸载。
- 便携版可自动选择并验证 Portable ZIP，防止路径逃逸、符号链接和解压炸弹，再通过事务脚本覆盖升级并清理暂存目录。
- CI 新增 Ruff、mypy、覆盖率门槛、Rust clippy、真实浏览器扩展加载、真实下载、便携升级及安装覆盖/卸载 smoke。
- 删除不参与发布的 Kotlin/Compose 与 pywebview 旧桌面壳，正式架构统一为 Tauri 2 + React + Python Core。

桌面端、Core、Native Host 与本次有改动的浏览器插件统一为 3.0.8。
