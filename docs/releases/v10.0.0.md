# HLS Downloader 10.0.0（发布草案 / Release draft）

10.0.0 是清理历史架构后新产品线的首个版本。当前处于发布准备阶段，尚未发布；以下源码改动不代表本版本已经通过 Windows 成品、安装、升级或实机验收。

## 主要变化

- #119：移除历史 Kotlin Compose 工作台和仅为其服务的 Gradle/JDK、CI、构建与验证链路。Rust Core + Slint 成为唯一维护的桌面 UI 路径；保留共享原生 MSI 工具与验收覆盖，不改变用户数据或协议身份。
- #120：主题可选“跟随系统 / System”“浅色 / Light”“深色 / Dark”；跟随 Windows 应用主题并随系统变化更新。已保存的 `dark_mode=true/false` 分别沿用深色/浅色，新安装默认跟随系统；非 Windows 的系统主题回退为浅色。
- #120：任务详情速度图增加当前、峰值和平均速度。峰值取可用历史样本与当前速度的最大值，平均值取可用样本的算术平均，不宣称是整个任务的活动时长平均。
- #120：完成提示音开关旁增加“试听提示音 / Preview sound”，立即复用实际完成提示音播放路径。

## 从 5.x/7.x 升级

- **7.x → 10.0.0**：MSI 采用原升级身份原地覆盖升级，保留任务和设置。产品版本变为 10.0.0，但数据目录仍是 `%LOCALAPPDATA%\HLS Downloader\v7`，数据库 schema 仍为 7；IPC 管道、Native Messaging Host、浏览器扩展身份和 MSI UpgradeCode 均不改名。版本比较按数字组件处理，10.0.0 高于 7.x。实际 MSI 升级及回滚验收仍是正式发布门禁。
- **5.x（Tauri/Python）→ 10.0.0**：备份旧配置、任务库和下载文件，然后全新安装并重新配置。**本版没有自动迁移 5.x 数据、设置或凭据的导入器**。5.x 使用 Python 的 `config.json` 与旧数据库；原生 Core 打开独立的 `v7/data.db`，不可直接用旧库替换。旧下载文件不会因本次版本号变化被主动迁移或删除。
- 以上为安装版升级说明；便携包须按对应便携升级流程处理，不应与安装版数据目录混用。

Windows x64 安装包未签名，更新需手动安装。Chrome／Edge 使用配套 Chromium 扩展；Firefox 提供待签名包和源码，标准版永久安装仍需 Mozilla 签名。

历史 `docs/validation/` 与此前发布说明保留原版本和哈希，不作为 10.0.0 新验收记录。正式成品、同源检查与文件哈希以后续发布附件为准。

## English summary

10.0.0 starts the clean Rust Core + Slint product line: historical Compose-only tooling is removed (#119), and System/Light/Dark themes, numeric speed statistics and completion-sound preview are restored (#120). This is a release draft, not a claim of packaged-release acceptance. The MSI upgrades 7.x in place while retaining the existing profile/settings and upgrade identity. Users of the 5.x Tauri/Python application must back up and install fresh; automatic migration of its database, settings and credentials is not implemented.
