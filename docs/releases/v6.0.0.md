# HLS Downloader v6.0.0

现网产品切到单一常驻 Rust 进程：`HLSDownloader.exe`（Slint 工作台 + `native_shell` Core）。安装包不再带 Python、Tauri 或 WebView2。5.x 的 `backend/`、`frontend/` 仍留在仓库里当行为规格，直到删除它们。

具体变化：

- GitHub Windows Release 只发 `HLSDownloader-v6.0.0-Windows-x64-{Setup.exe,Portable.zip}`，由 `scripts/build_v6.ps1` 构建
- Setup.exe 执行 `register-native-host.ps1 -Cutover`，把现网 Native Messaging host 指到 v6 二进制
- 随包打入与 5.x 同一针定来源的 `ffmpeg.exe` / `ffprobe.exe`；`libmpv-2.dll` 有则打入，没有则播放降级
- UI 与扩展只连 `\\.\pipe\HLSDownloader.v6`；只有 Core 打开 SQLite
- HTTP 热路径是 WinHTTP Range（ETag 变更 fail-closed，成功 Range 路径网络二次下载 0）
- HLS / LL-HLS / DASH / FTP / FTPS / SFTP 在 Rust 里按 5.x 语义移植；复杂多 Period DASH fail-closed，无 yt-dlp
- BT / magnet 走自制 `TorrentSession`（web seed；swarm 冻结），不是 libtorrent
- 首次启动可从 5.x `config.json` + `data.db` 迁移，进行中的任务导入为暂停

从 GitHub Release 安装 `HLSDownloader-v6.0.0-Windows-x64-Setup.exe`（或 Portable.zip），并按需更新浏览器扩展。
