# HLS Downloader v5.0.5

5.0.4 把无 Range GET 改回随到随写之后，浏览器 POST 重放还走默认缓冲。这一版对齐：无缓冲、来一块写一块。POST 仍然只下一遍，不用 Range 续传。

HTTP 单文件 Range/seek 拼接到此收口。还剩的是主列表 WebView、HLS/DASH 的 FFmpeg 收尾，以及 Python 核心体积，见 `docs/engine-stack.md`。

从 GitHub Release 安装 `HLSDownloader-v5.0.5-Windows-x64-Setup.exe`（或 Portable.zip）。
