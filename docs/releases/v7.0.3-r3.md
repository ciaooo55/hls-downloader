# v7.0.3-r3

本次交付为未签名 Windows x64 MSI、Chromium / Firefox 插件及 Firefox 审核源码。MSI 产品版本仍为 7.0.3，发布修订号为 r3。

## 主要修复

- 安装向导提供安装目录选择；默认下载位置读取当前 Windows 用户的系统“下载”文件夹，跟随系统目录重定向，保留用户自选路径。
- 下载进度和速度更新、断点续传速度基线、文件后缀与媒体合并处理。
- 下载确认窗缩小为紧凑布局，文件名只编辑一次，请求详情默认折叠，底部下载操作固定显示；完善进度窗和完成窗的拖动、圆角与置顶行为。
- 本地播放使用集成控制的悬浮播放器，修复关闭、重开及空闲退出处理。
- 网页媒体识别、浏览器下载接管与字幕错误反馈；增加 QwenCloud 配置说明。服务密钥由用户配置并加密保存，不随源码或安装包分发。

## 使用说明

安装时可修改目标目录；首次下载默认保存到该电脑用户的“下载”文件夹，可在程序设置或下载确认窗中修改。

Chromium 插件 ZIP 用于解压后加载。Firefox ZIP 未签名，永久安装需要用户自行签名；审核源码包含构建说明。桌面端安装包同样未签名。

本次实际验证范围、产物摘要及限制见发布附件 `VALIDATION.md` 与 `SHA256SUMS.txt`。旧构建的测试记录不能替代当前安装包的验证；投屏、TVBox 和需要用户凭据或接收设备的功能不宣称完成实机验收。
