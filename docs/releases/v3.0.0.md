# HLS Downloader v3.0.0

这是面向稳定性的主版本发布，重点是减少浏览器接管、插件通信、安装更新和下载运行中的边界异常。

- 桌面端、后端接口、前端和浏览器插件版本统一到 3.0.0；桌面端会提示低于 3.0.0 的插件升级，但保留上一版插件的兼容下载能力。
- 浏览器插件继续保留 Chrome / Edge 通用包，以及两套 Firefox 包：网页显示版与网页不显示版仍使用不同固定 ID。
- 加固浏览器 Cookie 读取：`magnet:`、`blob:`、`about:blank` 等不支持 Cookie 查询的地址不会再导致插件接管流程失败。
- 保留当前的网页来源 Referer / Origin / Cookie / 请求头传递、手动可编辑请求头、队列确认弹窗、视频旁资源按钮、HLS / DASH / 直播录制和边下边播能力。
- 发布流程继续产出 Windows 安装包、便携包、Chrome/Edge 插件、两套 Firefox 插件及源码包。
