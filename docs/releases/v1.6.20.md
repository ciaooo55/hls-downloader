# HLS Downloader v1.6.20

- 网页播放页的资源操作面板收紧为 344px：默认只显示目标视频的名称、清晰度、大小和来源信息，长链接不再占用界面；“下载 / 投屏 / TVBox”三个动作横向清晰排列。
- 浏览器工具栏弹出页同步缩小，去除默认展示的长资源 URL，保留下载、电视推送、清晰度和必要的来源信息。
- 浏览器接管确认窗调整为紧凑布局和 360×405 默认尺寸；直接确认即可下载，改名、分类、保存目录与记忆规则放进“保存选项”。
- 投屏与 TVBox 操作继续每次弹出设备选择；选择后按钮会明确显示目标设备，未发现设备时提供清晰的重试说明。
- Firefox 两个发布变体在桌面端明确标注：网页显示版 `browser@hls-downloader.ciaooo55.com`，网页不显示版 `hls-downloader-store@ciaooo55.com`。两者功能文件一致，仅发布 ID / 商店入口不同。
