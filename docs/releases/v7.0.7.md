# HLS Downloader 7.0.7

保留原生中文界面及现有下载、播放、字幕、投屏和工具功能，整合统一界面、下载核心优化及浏览器交接修复。

## 主要变化

- 原生工作台、设置、详情、任务工具和小窗口统一石墨/钴蓝主题、图标、圆角和反馈样式；浏览器插件弹窗与网页媒体浮层同步调整。
- 浏览器插件保留签名地址、Cookie、Authorization 和精确 POST 正文；宿主未安装与浏览器禁止访问分别提示。已消耗的浏览器响应继续保全，持久接收回执与恢复语义保留。
- HTTP 与 curl 使用有界流式缓冲、正文完整性校验及可停止的传输；范围检查点按可靠写入量提交，重试增加抖动，curl 进程并发受限。
- 运行任务使用内存控制、进度镜像和合并上报；周期 SQLite 写入交给后台线程，状态转换仍同步持久化。修复嵌套释放、旧控制/缓存值覆盖、进度冲刷序号阻断后续更新的问题。
- 异常退出后按可靠 HTTP 范围检查点恢复已下载进度，避免数据库更新滞后导致重启显示为零；续传仍重新验证远端资源身份。
- FTP/FTPS 增加多连接传输与主动模式回退；暂停恢复保留资源身份校验，关闭续传时不会复用旧分段完成表。
- DASH 支持 SegmentList 字节范围、SegmentBase/SIDX、整文件 SegmentBase 和兼容的点播多 Period；复用初始化段时也保留 Period 时间线边界。
- HLS 点播分片批量同步后记检查点；设置页提供 TS 无损封装为 MP4，保留多音轨，封装失败保全原始下载。

## 验证与发布身份

本机源码验证记录见 [外部源码整合记录](../architecture/source-integration-20261117.md)。最终版本必须通过同提交的源码 CI、安全检查、候选安装/升级/回滚、真实 Edge/Firefox 接管、原生 UI/媒体及持续下载验收。发布附件的来源、组件身份和 SHA-256 以随包证据为准，不能用其他版本的报告替代。

## 已知范围

- Windows EXE/MSI/Portable 沿用未签名手动安装方式；自动更新仍要求可信签名。
- Firefox 提供待 Mozilla 签名 ZIP 和审核源码，标准 Firefox 永久安装需要签名 XPI。
- 真实投屏/TVBox 接收端、付费云字幕质量和物理多显示器切换保留明确的验收边界，不将模拟或软件缩放结果写成实机通过。
- 不支持解密 DRM；DASH 动态多 Period、跨 Period 的整文件轨道及编码族切换仍有限制。SFTP、BT、字幕、播放和投屏等现有扩展能力继续保留。
- 未进行 IDM 同条件原版运行对照，不以源码相似或本项目自测证明性能等同 IDM。
