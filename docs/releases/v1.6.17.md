# HLS Downloader v1.6.17

- 投屏设备搜索修复了 SSDP `MX: 3` 与 2.5 秒等待窗口相互矛盾造成的随机漏设备问题，并补充 MediaRenderer / AVTransport v2 搜索；同一 IP 下控制地址不同的播放端会分别列出。
- 当前局域网实测可发现 `Phicomm p230`、`当贝投屏T0`、`投屏电视P8` 三个独立 DLNA 播放端。
- Firefox 网页显示版恢复使用已发布 AMO 条目的 `browser@hls-downloader.ciaooo55.com` ID；网页不显示版使用独立的 `hls-downloader-store@ciaooo55.com` ID。两者功能相同，Unsigned.zip 和 Source.zip 的 ID 均一一对应。
