# HLS Downloader v1.7.0（草稿，随 M1/M2 里程碑滚动补充）

- 新增原生 DASH 下载引擎：静态点播 MPD（SegmentTemplate 的 $Number$/$Time$ 与 SegmentTimeline、SegmentList、BaseURL 单文件形式）不再整体委托 yt-dlp，改由内置分段引擎下载——分片级实时进度/速度/ETA、随时暂停恢复且已完成分片跨会话复用、与 HLS 相同的限流共享重试策略，最后用 ffmpeg 无损合并音视频轨。
- 引擎边界清晰安全：动态（直播）MPD、多 Period、字节区间分片等超出范围的清单会在下载任何媒体数据之前自动回退到原有 yt-dlp 兼容引擎，行为与之前完全一致；DRM/ContentProtection 保护的内容仍直接判定为不支持，绝不尝试绕过。
- 自动选择最佳轨道：视频按分辨率优先、码率次之，音频取最高码率；后续版本将开放语言/清晰度手动选择。
