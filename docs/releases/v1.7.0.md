# HLS Downloader v1.7.0 · 插件 2.0.0

里程碑版本：下载能力完成态 + 全新界面。浏览器插件自本版起使用独立版本线（2.0.0）。

## 原生 DASH 引擎（点播 + 直播）

- 静态点播 MPD（SegmentTemplate $Number$/$Time$ 与 SegmentTimeline、SegmentList、BaseURL 单文件）由内置分段引擎下载：分片级实时进度/速度/ETA、随时暂停恢复、已完成分片跨会话复用、与 HLS 相同的限流共享重试策略，ffmpeg 无损合并音视频轨。
- **直播 DASH 录制**：SegmentTimeline 形态的动态 MPD 进入录制模式——按时间轴身份去重增量下载、live_state.json 崩溃恢复、停止即合并、停更自动收尾、支持录制时长上限，与直播 HLS 能力完全对齐。
- **边下边播与投屏**：DASH 视频轨下载中即可预览与投屏。
- 超出范围的清单在下载任何媒体数据前自动回退 yt-dlp 兼容引擎；DRM 内容仍严格拒绝，绝不绕过。

## 下载能力

- **轨道手动选择**：多清晰度/多音轨的 HLS 与 DASH 在新建任务时可选（默认自动最佳），选择随任务持久化，重试时失效自动回退。
- **每任务限速**：任务详情可对单个任务限速（与全局限速取更严者），立即生效、入库持久。
- **HTTP 尾段分裂（IDM 式 end-game）**：空闲连接自动分裂进行中分块的剩余区间，文件尾部不再受限单连接；单块文件也能多连接。
- 剪贴板监视支持整组链接批量导入；失败任务一键复制诊断信息；任务详情速度曲线。

## 全新界面（Turn 3 设计）

- 暖色双主题（浅色暖白 / 深色暖调），桌面与插件同一设计语言。
- 新建下载改为非模态浮层：粘贴即识别，任务列表保持可见。
- 任务行悬浮操作条（暂停/预览/投屏/复制/删除/更多）；限速浮层菜单；侧栏连接卡与断开排查气泡。
- 容器查询响应式：窄窗口侧栏收为图标条、表格降列、更窄时切换单列卡片。
- 插件弹窗 400×640 重做：状态点、主题切换、清晰度浮层菜单、版本底栏。

## 安全

- 修复本机 API 令牌可能被提交进仓库的隐患：`config.json` 改为不再纳入版本管理（仅保留无密钥模板 `config.default.json`），历史上出现过的令牌在启动时自动轮换为新的每机独立令牌，用户无需任何操作。

## 插件 2.0.0

- 独立版本线，与主程序解耦；双 Firefox 发布 ID 与六文件发布流程保持不变。
- Popup 与页内嗅探面板全面换肤（双主题跟随系统或手动）。
