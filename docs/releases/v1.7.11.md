# HLS Downloader v1.7.11

- 改进 HLS 边下边播启动：先准备连续可播放的起始分片，再恢复满并发下载；用户拖动播放位置时仍优先下载目标分片和后续分片。
- 优化 HLS 下载进度：未完成任务显示“预计总大小”，避免把已下载量误当成总大小。
- 增加桌面端运行日志：Windows 无控制台运行时会写入本地滚动日志，便于定位偶发闪退或卡死。
- 增加桌面端与浏览器插件版本对应提示：旧插件不会被强制禁用，但会提示使用同一个 Release 中的 Chrome/Edge 或 Firefox 插件包升级。
- 保留浏览器请求头、Cookie、来源页面、确认窗队列、误弹窗站点抑制和已有下载接管逻辑。

浏览器插件版本：2.0.11。
