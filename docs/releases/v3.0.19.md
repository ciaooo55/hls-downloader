# HLS Downloader v3.0.19

- 网页插件的单资源悬浮下载按钮新增“更多操作”入口；打开后可直接投屏或推送当前已识别的媒体链接，不必先创建下载任务。
- 修复网页投屏/TVBox 推送丢失桌面请求 ID 的问题；设备选择和完成状态现在可以正确回传插件。
- 浏览器右键菜单新增“投屏媒体链接”和“推送媒体链接到 TVBox”；MSE `blob:` 资源仍会安全打开关联资源面板，不会伪造不可用链接。
- 已完成的本地媒体任务在右键菜单和行内操作中提供“投屏已下载文件”和“TVBox 推送已下载文件”，避免将原始远程链接误发给电视。
- 桌面工具栏的投屏与 TVBox 操作先选择“本机文件”或“媒体链接”，再扫描并选择目标设备。
- 软件内“浏览器插件”窗口现在直接显示 Firefox Add-ons 官方地址，并可用系统默认浏览器打开安装页。
