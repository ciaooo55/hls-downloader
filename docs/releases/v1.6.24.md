# HLS Downloader v1.6.24

- 新增 HLS 外挂字幕下载：主清单里的字幕轨道（EXT-X-MEDIA TYPE=SUBTITLES）不再被忽略，下载完成并校验通过后自动按语言保存为独立的 `.vtt` 和 `.srt` 双格式文件（如 `剧集.zh.vtt` / `剧集.zh.srt`），多语言、强制字幕（forced）各自成档；字幕分片会正确应用时间戳偏移并去除相邻分片重复的字幕行。
- 字幕下载完全不影响主任务：字幕源失效、加密或内容为空只记录日志并跳过，已合并校验的视频绝不受影响；设置中可关闭"下载 HLS 外挂字幕"。
- HTTP 下载速度显示重做：改为最近数秒的滑动窗口实时速率，续传大文件时不再把已完成部分算进速度导致虚高，停滞后速度会如实归零；HTTP 任务补上了缺失的剩余时间（ETA）估算。
- HTTP 分段下载进度改为字节级实时推进：不再整块（8 MiB）跳变，暂停时进度精确回退到可续传的位置，与恢复后的实际起点一致。
