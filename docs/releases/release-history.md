# 历史修复摘要

可下载版本以 [GitHub 发布页](https://github.com/ciaooo55/hls-downloader/releases)为准；每个主要版本只保留最后一版，v7 保留一个未签名预发布。移除重复发布不会移除对应的源码标签。下面是早期 v7 改动摘要，不能代替后续版本各自的验收记录；架构见[模块图](../architecture/v7-module-map.md)。旧版发布文字、单次本机记录和迭代日志已合并，详细原文保留在同一仓库的 Git 历史中。

| 历史阶段 | 与当前维护有关的改动 |
| --- | --- |
| r2–r4 | 浏览器接管、媒体归属、下载进度、播放器入口及字幕音频预取 |
| r5 | 完成及删除任务的缓存清理；HLS/DASH/HTTP 边播边下；主窗口播放器及下载目录选择 |
| r6 | WebCrypto/MSE 媒体归属、伪装分片后缀及无后缀清单的音频解码 |
| r7 | Firefox POST 不重复提交；升级时保留用户显式选择的安装路径 |
| r8 | 连续字幕窗口响应身份匹配；有限窗口真实云端字幕验收 |
| r9 | HTTP 断流控制响应、筛选清理范围；移除生产 ffprobe 和完整图标库 |
| r10 | 行内快捷操作、提示层、插件分页和受限高度弹窗布局 |
| r11 | 行内按钮 Enter、清晰度状态隔离、复制失败处理及字幕设置恢复 |
| r12 | 批量部分失败保留输入、队列数字编辑及命名、FTPS 入口；重新执行模块和安装验收 |

历史机器报告及截图继续保留在 `docs/validation/validation-*.json` 和对应日期目录。报告只证明其中列明的受测文件与场景，不能将旧通过数量、网站结果、云端质量或设备表现转作当前版本的全量保证。

要读旧文档，使用 `git log --all -- <文件路径>` 和 `git show <提交>:<文件路径>`，无需创建另一分支、worktree 或源码副本。r12 发布标签保存了本次合并前的旧版 Markdown。
