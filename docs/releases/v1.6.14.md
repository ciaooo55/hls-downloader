# HLS Downloader v1.6.14

- 对插件的 `data-download-url` / `data-url` 目标增加协议白名单：只接受 HTTP(S) 或 magnet，拒绝 `javascript:`、`data:` 等不可下载协议，进一步避免误接管。
- 支持安全重放小型 JSON 或 URL 编码 POST 下载请求：请求体加密保存、只单次流式下载、不使用 Range；multipart 上传和其他有副作用的方法不会被重放。
- 保留 v1.6.13 对明确下载语义链接的支持，以及现有精确点击匹配机制。
- 插件现可在用户明确接管下载时保留小型 JSON 或表单 POST 请求；桌面端会加密保存请求体，并以单次单连接 POST 重放，覆盖 API/表单生成下载文件的站点。
- 不重放 multipart 上传、文件上传、未知方法或超大请求体；这类请求会回退为普通下载流程，避免重复提交带来的副作用。
