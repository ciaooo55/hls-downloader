# HLS Downloader v1.7.3

- 视频旁“选择资源”浮标在拖动期间不再被播放器的 `timeupdate` 刷新替换，鼠标与触摸拖动可稳定生效并保存位置。
- 浏览器扩展对 iframe 播放器始终使用浏览器标签页的顶层 URL 作为来源网页，不会把 CDN iframe 误作来源页。
- 手工粘贴 `surrit.com` 的媒体清单时，自动预填 `Referer: https://missav.ai/` 与 `Origin: https://missav.ai`；用户可覆盖。下载器 HLS 客户端已实际验证该上下文可读取清单和首个分片。

Firefox 插件版本：2.0.3。
