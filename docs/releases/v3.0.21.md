# HLS Downloader v3.0.21

本版本针对真实下载失败、浏览器接管竞态、投屏和合并收尾进行了稳定性修复：

- 浏览器来源的签名文件遇到 404/410 时，会在确认存在浏览器请求上下文后使用浏览器兼容连接重试；普通 404 不会被无条件重复请求。
- 修复 Chromium 暂停原生下载后短暂变为 `interrupted` 导致接管流程提前退出的问题；用户主动失败或取消的下载仍不会被误接管。
- 删除任务增加终态收尾等待、重复删除合并和 Windows 文件锁有限重试，删除失败时保留任务并给出可重试提示。
- 完成任务、直播任务、合并任务和普通下载统一显示“已下载 / 总大小”。
- 支持把已完成的本地文件直接投屏/推送；HTTP/Torrent 下载获得连续可播放范围后，可以将已验证的本地范围共享给设备，设备不会重新下载原始远程链接。
- FFmpeg 合并增加预计时长上限、无损/重新编码阶段日志、错误尾部日志和完成校验，减少时间轴异常造成的超长文件与末尾卡死。

本版本包含 Chrome/Edge/Chromium MV3 源码和 Firefox MV3 源码；Firefox 用户也可以直接从[官方插件页面](https://addons.mozilla.org/zh-CN/firefox/addon/hls_downloader/)安装。
