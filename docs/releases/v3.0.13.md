# HLS Downloader v3.0.13

这是浏览器来源媒体下载的网络兼容性热修复版本。桌面端升级到 v3.0.13；浏览器插件未修改，继续使用 v3.0.12。

- 修复透明代理/TUN 的 Fake-IP DNS（`198.18.0.0/15`）被误判为私网，导致公网CDN的浏览器来源HLS任务报 `PRIVATE_DESTINATION_BLOCKED`。
- 仅允许域名经DNS解析得到该特定代理假地址；直接访问该保留地址、回环、RFC1918内网、链路本地地址和混合私网DNS结果仍会被阻止。
- 修复网络策略错误被当作瞬时网络故障重复5次的问题；现在会立即显示可操作的失败原因。
- 桌面和插件版本独立：未修改插件时不会强迫插件升版或重复发布插件资产。
