# HLS Downloader v3.0.14

这是浏览器媒体识别、下载接管和 HTTP 下载收尾修复版本。桌面端与浏览器插件均升级到 v3.0.14。

- 修复 iframe 播放器读取错误资源页键导致悬浮窗长期停在“正在识别”。
- 内容脚本和 MAIN-world 媒体钩子增加启动期事件缓存与回放，减少快速播放时丢失首个清单或 MSE 证据。
- HLS 多清单探测短暂失败时在保护窗口后显示有限候选，不再无限等待。
- “排除本站”按顶层页面主机生效，统一处理端口、`www`、子域和旧设置值。
- 修复 popup 初始化期间排除本站、Cookie、接管开关和恢复提示不可用；右键批量选择修复 tabId 为 0 的页面。
- Chromium 接管在 `downloads.onCreated` 后立即暂停原始下载，接管失败或用户拒绝时自动恢复，降低先下载后弹窗和重复文件。
- HTTP 分段下载在所有尾块落盘后发送明确的 100% 进度样本，并显示最终写入/校验阶段，避免界面长期停在 99.x%。
