# HLS Downloader v3.0.7

本版本集中修复直播录制、短效签名文件下载、浏览器媒体归属和多浏览器连接稳定性，并完善覆盖升级与发布更新链路。

## 下载与录制

- 支持 LL-HLS 独立音视频轨长期录制、暂停恢复和最终合并，忽略未完成 `EXT-X-PART` 尾分片，不再将其误报为“分片缺少 URI”。
- 清理 Privatecams 子清单中的一次性 `_HLS_msn`、`_HLS_part`、`_HLS_skip` 轮询游标，同时保留真实 session、token 和质量参数。
- MP4/普通文件探测改用受限 GET，补齐超时终态、严格 Range 校验、If-Range、ETag/Last-Modified、动态分片和字节级续传。
- HLS、DASH 与 HTTP 对 429/503 使用任务级共享冷却；分片、检查点与最终文件采用落盘后原子发布，降低断电或进程退出后的损坏概率。
- 短效签名刷新覆盖常见 token/signature 以及 `s`、`e`、`_t` 参数，刷新时保留质量和语言选择。

## 浏览器插件

- 每个 `<video>` 独立保存播放证据；直链精确匹配，多个 MSE 播放器时禁止模糊归属，减少悬浮按钮串到广告或其他播放器。
- 按 `requestId` 关联重定向链、frame 请求上下文、响应大小和文件名，不再用顶层网页 Referer/Origin 覆盖浏览器实际请求。
- Native Messaging 与本机 HTTP 双通道支持多个浏览器、不同插件版本和 Core 重启重新配对；请求链有界清理，避免直播页面长期运行后变慢或假失联。
- 桌面端会显示每个浏览器的插件版本；旧版插件即使暂时离线也保留升级提示，并提供同版本 Release 入口。

## 更新与安装

- 桌面在线更新继续使用 GitHub Release，并校验版本化安装包的可信下载地址、大小、MZ 文件头和 GitHub 提供的 SHA-256 digest。
- 安装版更新下载复用普通 HTTP 任务的续传、重试和进度能力；覆盖升级保留设置、任务历史和下载文件，并切换到版本化 Native Host。
- 正式标签发布会自动比较上一标签以来的 `extension/` 变化：插件有改动才发布 Chromium 与 Firefox 资产，没有改动则只发布桌面安装版和便携版。
- 桌面端、Core、Native Host 与本次有改动的浏览器插件统一为 3.0.7。

## 已知边界

- DRM、SAMPLE-AES、受保护 EME 和无法重放的 `blob:`/POST 媒体不会尝试绕过。
- Chrome/Edge 商店版和 Firefox AMO 版由商店自动更新。Windows 开发者模式加载的解压插件需在桌面覆盖升级后手动“重新加载”；Firefox 独立自动更新需要 Mozilla 签名包和 HTTPS 更新清单。
