# v7.0.3-r12 未签名预发布版

本版修复批量添加失败后丢失输入、队列数字难以编辑及 FTPS 链接被桌面拒绝的问题，并按模块重新执行下载、恢复、播放器、缓存和安装验收。产品版本仍为 7.0.3，r12 区分交付修订；安装包和插件均未签名。

## 修改后的行为

- 批量添加逐条处理：中间失败不跳过后续链接，只保留失败项；显示已处理和失败数量、原因，修正后仅重试剩余项。成功处理包含复用已有任务。
- 新建、批量、队列保存增加忙碌状态和重复提交保护，保存中按 Escape 不会提前关闭窗口。失败保留草稿。
- 队列优先级可以输入负号，数值可以清空后重写；越界禁保存；连续新建自动使用不同名称，达到 32 个时禁新建，自动优先级不超过上限。
- 桌面接受 FTPS；FTP/FTPS/SFTP 链接优先按传输协议识别，不因文件名以 `.m3u8`、`.mpd` 或 `.torrent` 结尾错误分流。

保留此前的主窗口播放器、下载中播放、完成后同窗口切换成品、缓存清理和插件交互修复。未增加依赖或播放引擎。

## 验收与体积

本轮桌面完整 **126 项测试（22 类）通过，0 失败**，JAR 构建成功。沙盒验收和初次夹具失败后的修正过程见 [模块验收](../validation/validation-module-audit-20261018.json)、[最终 MSI 与升级验收](../validation/validation-r12-installer-20261018.json)。逐项范围以 JSON 为准，不能用测试数量推断所有功能在所有环境都不会出错。

本轮还完成种子与磁力链接的实际元数据解析、文件勾选、peer 传输和选中输出校验；解析中关闭窗口不重开，不生成意外任务，错误种子保留可见反馈。直播有限窗口完成暂停/恢复及全部视频帧与音轨校验。r11→r12 同版本修订升级替换正确 JAR，只保留新产品安装登记；真实计划任务和设置在升级及 Core 重启后保留，随后卸载成功。

本轮重新执行了 HTTP、FTP/SFTP、真实公网 FTPS、认证 POST、校验和、计划任务、请求刷新、断流/超时/HTTP 错误恢复、文件名/后缀、任务导出导入和 LAN 分享。播放器验收覆盖 TS、fMP4、AES、外置音轨、DASH、HTTP 的未完成播放、完整时间轴、seek、独立缩略图和成品切换；同时核对暂停保留断点、完成清缓存、删除未完成任务清缓存且保留无关文件、清理已完成记录保留成品。主界面覆盖真实下载、暂停/恢复、详情、批量失败重试、页面抓取筛选、队列操作、键盘焦点、播放器关闭和小窗口布局。

MSI **203,108,352 B（193.7 MiB）**，比 r11 增加 **12,288 B**；安装目录 **472,749,889 B（450.8 MiB，263 个文件）**，增加 **9,961 B**。主要体积为 FFmpeg、libmpv 与裁剪 JRE；生产包不包含 ffprobe 和完整大图标库。本次沙盒约 5 秒闲置样本 RSS 合计约 **238.8 MiB**，占整机 CPU 约 **0.078%**，不构成跨电脑性能保证。

最终 MSI 已实际验证自选含空格安装路径、组件哈希、插件 ZIP 与解包文件一致、系统 Known Folder Downloads、真实 MDN 视频逐字节一致与缓存清除、界面连接和卸载。默认下载目录不写死盘符，跟随当前 Windows 用户的下载文件夹；已有用户自选配置保持其设置。

## 插件、交付与限制

插件本轮未改动，Chromium/Firefox ZIP 与 r11 完全相同；r11 的 380 项测试、类型检查、构建和 Firefox 原生弹窗 100%/150%/400px 限高交互证据见 [细节验收](../validation/validation-detail-polish-20261018.json)。本轮没有重新执行 Chromium 原生 UI，也没有上传音频或验收实体投屏/TVBox；不宣称所有网站媒体都可识别或绕过网站限制。真实系统关机/睡眠未测试。

二进制生产源码提交 `36af74606f3d5398ba9e767251f0fc7cdeef939d`；发布标签随后只增加测试夹具修正、验收文档与截图。Core、Host、Presenter、Updater、播放运行时及插件复用 r11，哈希见 BUILD-PROVENANCE.json。完整源码和插件源码 ZIP 从发布标签导出，不含用户配置、密钥、下载或构建缓存；Firefox 审核源码包随附。

当前包为 `release_ready=false` 的未签名预发布交付，手动安装更新，自动更新签名校验保持。canonical 功能合同的状态和排除项另见 [验证索引](../validation/v7-verification.md)，不能把两份不同范围的合同混为一谈。

发布验收只在 Windows Sandbox 安装运行产品。本说明记录 r12 发布时的产物与证据；后续源码整理或本机清理不改变已发布包，也不由本说明证明当前电脑无残余。用户下载、备份和其他项目不属于产品生成物。
