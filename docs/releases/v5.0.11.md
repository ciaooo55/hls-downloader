# HLS Downloader v5.0.11

5.0.10 把空闲入口换成了常驻 `HLSNativeShell.exe`。5.0.11 修的是浏览器接管：要能认出文件和媒体，但不能把普通点击当成下载。

具体变化：

- `?download=0` / `download=false` 这类播放页参数不再记成下载意图
- 扩展名只看路径，不再因为地址栏里带着 `.mp4` 查询串就把观看页当成文件
- 观看页上的 `file=episode.mp4` 仍是播放导航；点到 `.zip` / `.metalink` / `.mp4` 文件本身、`/attachments/`、`download=1`、`cd=attachment` 仍会接管
- 「保存」「Save」收藏类按钮不再当下载；「下载」「另存为」「保存到本地」仍会
- 补上 metalink / meta4 / f4v / 3gp / aac 等文件识别；HLS 分片和图片/脚本/OAuth 仍不抢

依据：`extension/lib/clickIntent.test.ts`、`extension/lib/resources.test.ts`。`extension/` 下 `pnpm test`：168 passed。

从 GitHub Release 安装 `HLSDownloader-v5.0.11-Windows-x64-Setup.exe`（或 Portable.zip），并更新浏览器扩展。
