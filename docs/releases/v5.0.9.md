# HLS Downloader v5.0.9

5.0.8 把 HTTP GET 收进同一个 `HLSNativeShell.exe`，但每次传输仍 fork 一份 `--job`。IDM 是在已经运行的进程里传文件。5.0.9 把 GET 接到监督进程已有的事件队列上：托盘进程在听的时候，任务在线程里跑 `run_job`，不再克隆一份二进制。`--job` 只在监督进程没启动（测试、无托盘）时当后备。

写入还是 Range seek 进同一个 `payload.downloading`，https 仍用系统 WinHTTP。HLS / DASH / 直播 / BT 仍在 Python 核心。总内存仍然包含 Tauri、Python、FFmpeg，不和 IDM 比。

从 GitHub Release 安装 `HLSDownloader-v5.0.9-Windows-x64-Setup.exe`（或 Portable.zip）。
