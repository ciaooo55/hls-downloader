# HLS Downloader v3.0.20

本版本重点修复浏览器接管、短效媒体链接和直播任务稳定性：

- 对带 `s/e/_t` 的短效媒体链接，在确认签名窗口仍有效时等待其生效，避免把可用链接误报为 403。
- 浏览器接管优先使用成功的真实媒体请求链；空 `video[src]`、页面控制器 URL 和未完成的签名请求不会再被误识别。
- Chromium 在响应头确认是直接下载后立即建立接管候选，Firefox 继续使用阻塞式响应接管；浏览器原生下载仅在桌面端确认接收后清理。
- Core 关闭前持久化可恢复任务，避免更新或桌面重启把直播误判为崩溃中断；普通即时下载不再被错误标记为全局定时队列任务。
- 删除操作增加并发合并、任务收尾等待和 Windows 文件锁有限重试；失败时保留任务并给出可重试提示。
- 任务列表各阶段统一显示“已下载 / 总大小”，直播明确标注总大小未知。

本版本包含 Chrome/Edge/Chromium MV3 源码和 Firefox MV3 源码；Firefox 用户也可以直接从[官方插件页面](https://addons.mozilla.org/zh-CN/firefox/addon/hls_downloader/)安装。
