# HLS Downloader 7.0.6

本次版本集中修复下载一致性、浏览器接管身份和发布恢复。保留现有原生界面、媒体下载、播放、投屏、字幕及其他功能。

- HTTP 下载正确解析相对重定向和带签名的地址，保留有效查询参数，并按来源限制请求凭据；正确消耗临时响应，避免把响应头当作文件内容。
- FTP 续传核对账户、路径及远端文件大小和修改时间；资源变化或续传状态无效时重新下载。服务端明确不支持 REST 时从头获取。
- SFTP 续传身份包含登录账户，避免切换账户后拼接不同文件。同账户更新密码仍保持身份，续传状态不保存密码。
- 并发创建相同下载时串行裁决，防止重复任务；浏览器下载匹配使用请求身份，避免仅凭相同文件名或路径误认任务。
- 更新检查使用实际编译的产品版本；正式发布恢复通过完整发布清单识别草稿，避免漏掉尚未公开的草稿。

发布门禁核对同一冻结源码及组件哈希，覆盖 EXE 安装启动、MSI/便携升级与故障回滚、Edge/Firefox 接管和凭据恢复、HLS/DASH/直播及音轨恢复，以及 1000 任务下的重绘和 30 分钟实际下载负载。具体结果与成品身份随包记录在 `ARTIFACT-MANIFEST.json` 和 `RELEASE-EVIDENCE.json`。

Windows 包未签名，需手动安装更新，自动更新继续要求受信签名。Firefox 提供待 Mozilla 签名 ZIP 与源码；标准正式版 Firefox 的永久安装需要签名 XPI。真实投屏/TVBox、付费云字幕质量及物理混合 DPI 未计为本轮通过项目。界面缩放验证使用软件缩放参数。
