# HLS Downloader v1.7.7

- 多个浏览器接管请求改为单窗口依次确认：当前请求处理完成或取消后，自动显示下一个；排队请求不会被浏览器错误提示为桌面端打开失败。
- 确认窗显示剩余待确认数量，默认尺寸调整为完整可见的紧凑布局。
- 无边框确认窗加入八方向边缘/角落缩放，可直接拖动改变大小；展开保存选项或网站请求上下文时，正文独立滚动，底部取消/下载按钮保持可见。
- 包含 v1.7.6 的浏览器 HLS HTTP/2/HTTP/3 协商修复。使用本机失败任务的真实 MissAV/surrit 请求上下文复测，返回 HTTP 200 和有效 HLS 清单。

Firefox 插件版本：2.0.7。
