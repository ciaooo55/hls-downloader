# HLS Downloader v5.0.3

继续抠下载引擎和落盘热路径，不换语言，不改拼接语义。

- HTTP Range：256 KiB 一批放到线程里写，事件循环继续收下一个 206；检查点对已打开的 `payload.downloading` 做 `fsync`，不再反复打开几 GB 的稀疏文件。
- Windows 打开 Range 载荷时带 `FILE_FLAG_RANDOM_ACCESS`；Linux 仍是无缓冲 `r+b`。
- 已拒绝 Content-Encoding 的响应走 `aiter_raw()`，避开 httpx ByteChunker 把半截 chunk 卡在迭代器里。
- HLS/DASH 分片 `write` 同样下放到线程。MPEG-TS 仍是 `concatf`；fMP4 仍是本地 ENDLIST + FFmpeg。
- 对照说明见 `docs/engine-stack.md`。

从 GitHub Release 安装 `HLSDownloader-v5.0.3-Windows-x64-Setup.exe`（或 Portable.zip）。
