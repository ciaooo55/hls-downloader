# HLS Downloader v1.6.6

## 浏览器扩展修复

- 恢复播放媒体资源的回退展示：即使页面没有及时触发播放事件，已捕获的 HLS、DASH 和视频文件仍会出现在媒体面板。
- 图片、动态网页端点（PHP/ASP/JSP 等）以及没有明确下载文件名的二进制响应不再触发下载接管或桌面确认。
- 浏览器下载创建后，无法确认是可接管文件的项目会立即交还浏览器，不会被强行作为普通文件处理。

## 投屏发现

- 投屏发现固定从实际私有局域网网卡发送多播请求，排除 Mihomo、VPN 和其他虚拟适配器。
- DLNA 设备描述与控制请求始终直连，不使用系统代理；同时支持 Chromecast mDNS 发现。
