# HLS Downloader v5.0.1

对照 IDM / AB Download Manager 之后，5.0.0 还差在：进度和完成仍可能再开 WebView。这一版把这两扇窗接到常驻监督进程。

- 下载开始/结束由核心直接推给 `HLSNativeShell.exe`：右下角进度条、完成窗（打开目录 / 打开 / 关闭），不再等主界面 WebView。
- 监督进程已热时，桌面不再预热确认/进度/完成三套 WebView2。
- 确认窗补上本地「保存到」路径、大小和类型；可执行文件完成窗只强调先打开目录。
- 仍不抄 IDM 挂钩，也不重写下载引擎。主任务列表仍是现有窗口。

从 GitHub Release 安装 `HLSDownloader-v5.0.1-Windows-x64-Setup.exe`（或 Portable.zip）。
