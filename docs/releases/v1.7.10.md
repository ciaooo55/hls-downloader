# HLS Downloader v1.7.10

- 修复 HLS 在 curl 网络连接短暂中断时被错误标记为“程序已关闭”的问题。清单与分片会作为可重试的连接错误处理，只有用户暂停、取消或应用实际退出才会中断任务。
- 浏览器自动接管会保留原始浏览器下载，直到用户在确认窗明确点击“下载”；取消、超时或拒绝后会自动恢复浏览器下载。
- 确认窗新增“再次点击后不再自动提示本站此类资源”。规则只匹配来源网页域名和 HLS、DASH、媒体或文件类型；扩展弹窗可以恢复本站自动提示，手动发送资源和 Ctrl 强制接管不受影响。
- 保留更新安装后的下载自动续传、边下边播、网站 Cookie 与请求头传递逻辑。

Firefox 插件版本：2.0.10。
