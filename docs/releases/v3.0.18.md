# HLS Downloader v3.0.18

- Firefox 扩展统一为 `hls-downloader-store@ciaooo55.com`：不再发布或白名单维护网页显示/不显示两个身份。
- 标签页徽标在切换标签和后台过期清理时自行刷新；不再需要打开插件菜单才清除旧红点。
- 直播页面的 MSE 分片、DOM 变动和 Shadow DOM 扫描已去重、限频和限量，悬浮下载按钮保持即时识别，同时避免聊天/分片频率拖慢网页。
- 浏览器接管的普通 HTTP 文件在标准多线程请求实际收到 403 时，会自动尝试一次 Chrome TLS 指纹兼容的单连接回退；成功请求仍保持原有多线程下载，不会降级。
- 桌面壳在默认端口被残留进程占用时会选择可用回环端口并记录启动错误，而不是崩溃退出。
