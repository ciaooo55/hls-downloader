# HLS Downloader v1.6.5

## 浏览器普通文件接管

- 修复 Manifest V3 后台休眠时丢失网页点击意图的问题，普通文件下载不会再因为点击与下载事件错开而留在浏览器中。
- 支持下载链接经过网关或 CDN 重定向后才生成最终文件地址的页面，仍要求同标签页或来源页证据，避免误接管无关下载。
- 旧版默认的 1 MB 接管阈值会自动迁移为 0 MB；用户手动设置的其他阈值保持不变。
- 接管脚本现覆盖 iframe 内的网页下载链接和按钮。

## 电视投屏

- 保留原有 TVBox 推送，并新增独立的 DLNA/UPnP 与 Chromecast 本机媒体投屏。
- 投屏设备发现会绑定实际私有局域网网卡，避免 VPN/代理虚拟网卡导致电视无法被发现；DLNA 设备请求始终直连，不经过系统代理。
- DLNA 与 Chromecast 投屏均支持暂停、继续和快进；未实现通用控制协议的 TVBox 保持仅推送与停止共享。

## Firefox 发布物

- 提供网页媒体面板版与无网页面板版两套 Firefox 扩展，各自使用独立发布 ID，并分别附带可审核的源码包。

## 验证

- 后端、前端与扩展测试均通过。
- Chrome 和 Firefox MV3 扩展生产构建均通过。
