# HLS Downloader v3.0.9

## 直播录制

- 支持直播窗口只有 `EXT-X-PART`、尚未出现完整 `EXTINF` 分片的 LL-HLS 源，不再长期停在 0/0、录制 0 秒后超时。
- PART 按媒体序号与 Part Index 去重，忽略尚未完成的 `PRELOAD-HINT`；完整父分片出现后先验证下载成功，再原子替换已录制 PART，避免漏片或重复时间轴。
- 支持 LL-HLS init map、BYTERANGE、AES-128、Delta Update 序号及编码器重启边界；真实 fMP4 PART-only 录制与 FFmpeg 输出时长已加入发布 smoke。

## 浏览器插件

- 可见视频触发播放后立即显示“正在识别”，资源归属未确认前下载按钮保持不可操作；已有播放中的播放器、SPA 新增播放器和延迟到达的资源均会主动同步。
- 修复 PART-only 清单未被识别成直播媒体的问题；多条候选清单检查完成前不再让悬浮窗消失。
- 同一播放器同时出现普通直播与 LL-HLS 路线时保留所有已验证候选，优先完整分片路线，不再强制丢弃可稳定录制的普通 HLS 地址。
- Chromium 生产构建新增真实浏览器 E2E，验证播放后即时识别悬浮窗确实出现。

## 桌面与下载验证

- 最大化按钮改用权限清单已授权的 `isMaximized/maximize/unmaximize` 调用，支持按钮与标题栏双击切换并同步最大化/还原图标。
- 实际隔离 release 窗口验证了最大化与还原两种 Win32 状态，不仅是前端单元测试。
- 真实 HTTP smoke 记录服务端同时在途 Range 请求；并发 2 必须观察到至少 2 个并行连接、多个不同范围并通过暂停恢复后的 SHA-256 校验，否则发布测试失败。

桌面端、Core、Native Host 与本次有改动的浏览器插件统一为 3.0.9。
