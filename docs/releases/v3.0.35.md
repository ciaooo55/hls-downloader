# HLS Downloader v3.0.35

v3.0.34 的安装包没发出去：一进页面就改写 `Blob.slice`，Chrome 播放内存里的 `blob:` 媒体时浮层冒烟过不了。本版带上 3.0.34 的接管修复，并且只在已经对上 HTTP 来源的 Blob 上才挂钩 `slice`。

- PHP/ASP 下载只要服务器给了明确的文件 MIME（zip / pdf / apk 等），即使文件名还是 `export.php` 也会接管。只标 `octet-stream` 的 `advert.php` 仍不接。
- `fetch` 得到的 Blob 再 `slice()` 改 MIME 后触发的下载，会对上原来的 HTTP 地址。
