# HLS Downloader v1.7.6

- 浏览器接管确认窗改为稳定的窗口内滚动布局：展开保存选项或请求上下文时不会再把无边框窗口撑出屏幕，标题栏可直接拖动窗口。
- 资源面板每项完整显示实际下载地址，地址过长会在面板内换行；面板自身可滚动。
- “选择资源”默认贴近当前实际播放的视频：右侧有空间时显示在视频外侧，否则贴在视频右上角。拖动位置只在当前播放会话保留，不会漂移到下一个网页或视频。
- 恢复严格的播放归因：精确匹配的 `<video>/<source>` 资源独占候选；MSE/blob 播放保留播放前三分钟预加载、以及本次播放中出现的 HLS/DASH 清单，不再把小型 `video/*` 响应、预览或广告片段误认为目标视频。
- 浏览器接管的 HLS 客户端不再强制 HTTP/1，使用浏览器优先的 HTTP/2/HTTP/3 协商。截图中的 surrit 清单以来源页 Referer/Origin 实测返回 HTTP 200 与有效 HLS 清单。
- Release 新增 `HLSDownloader-Chrome-Edge-Extension.zip`，Chrome 与 Microsoft Edge 共用该 MV3 扩展包。

Firefox 插件版本：2.0.6。
