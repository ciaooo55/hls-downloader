# HLS Downloader v1.6.8

- 浏览器插件改为完整 Native Messaging 使用体验：用户不再需要查看、复制或配置固定 Token。
- 本机管理接口首次启动自动生成随机内部凭据，只绑定 `127.0.0.1`；设置、URL 与 localStorage 不再暴露该凭据。
- 恢复并强化播放器识别：主捕获器、Fetch/XHR 监听器同时覆盖 iframe；网络资源按 frame、页面与播放时间关联，避免广告、图片、PHP 页面和后台预览流误判为当前视频。
- 视频播放期间不再因每次 `timeupdate` 重建悬浮窗口，降低页面重排与闪动。
- 修复投屏发现：所有有效局域网网卡并行发送 SSDP；忽略失效链路本地、VPN 与虚拟网卡，单个网卡失败不会终止扫描。
- Firefox 网页显示与网页不显示两个变体均为完整功能版，只使用不同发布 ID；Release 固定为安装包、便携包及两个变体各自的插件/源码包共六个文件。
- GitHub 发布流程改为可重复执行；已有同 tag Release 会覆盖上传资产而不是失败。
