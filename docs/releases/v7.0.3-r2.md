# HLS Downloader 7.0.3-r2

本次为 7.0.3 的未签名修订包，修复浏览器下载接管、页面导航导致 POST 身份丢失、iframe 快捷键重复面板、弹窗尺寸和桌面操作问题。软件版本仍为 7.0.3，发布修订号为 r2。

## 下载与使用

- 桌面程序：安装本次 MSI；覆盖升级需要管理员权限，升级验收已确认保留任务和下载文件。
- Chrome / Edge：解压本次 Chromium ZIP，在扩展管理页加载解压目录；先启动桌面程序完成原生通信注册。
- Firefox：ZIP 未签名，永久安装需要办理签名；开发测试可在 about:debugging 临时加载 manifest.json。另附审核源码和 AMO-BUILD.md。
- 桌面程序与插件应使用本次配套文件。安装包、扩展均未签名，未进行商店上传。

## 下载接管

默认开启自动接管，最小文件大小为 0。普通下载交给桌面程序。POST 表单、Blob/data 生成文件由浏览器先完成原请求，再导入桌面任务；成功后清理浏览器源副本，拒绝或导入失败时保留文件。POST 不自动重放。按住 Alt、关闭接管或命中排除规则时保留浏览器下载。

- 最终 MSI 的干净安装和旧版到新版真实升级通过；安装后的组件、插件与本次包哈希一致，任务和下载文件保留。

发布 tag 指向同步后的 main 提交。附件 ARTIFACT-MANIFEST.json 绑定源码提交、树及产物 SHA-256，SHA256SUMS.txt 可用于下载后核对。Release-Evidence.zip 保存本次最终实测结果、执行脚本、日志、播放器截图及已发生失败的记录。
