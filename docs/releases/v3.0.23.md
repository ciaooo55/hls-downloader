# HLS Downloader v3.0.23

本版本集中处理长时间合并、覆盖升级可靠性、浏览器 Cookie 权限和故障恢复，保持既有 HLS、DASH、HTTP、BT、投屏与浏览器接管能力不变。

- 纯 MPEG-TS 且没有 init map/discontinuity 的任务使用 FFmpeg `concatf` 快速本地拼接；fMP4、独立音轨和存在时间轴切换的流继续使用本地 HLS 时间轴合并。
- 大型 HLS、DASH 与独立音视频后处理按输入/输出磁盘调度；同一磁盘避免多个 FFmpeg 同时争抢，不同磁盘仍可并行，等待和取消状态可见。
- 修复本机任务中 FFmpeg 本地 HLS 输入超过 600 秒无输出后误入 `libx264` 全量重编码、导致数小时合并的问题。
- SQLite 启动时执行完整性检查，迁移与正常关闭创建一致性备份；数据库损坏时自动恢复最近可用备份并保留损坏副本。
- 安装版覆盖升级先保留旧程序，安装失败或中止时事务回滚；便携升级使用同卷移动保留下载目录，避免大文件复制和磁盘空间翻倍。
- Native Messaging 冷启动直接等待桌面 presenter，会话建立后立即返回，减少浏览器悬浮按钮拉起桌面端时的额外等待。
- 浏览器 Cookie 改为按站点授权，默认不读取；诊断复制隐藏 URL 凭据、签名参数和 fragment。
- Firefox 帮助入口固定指向官方 Add-ons 页面；浏览器插件推荐版本同步为 3.0.23。

验证覆盖 Python 全量测试与覆盖率门槛、真实 MPEG-TS/fMP4 FFmpeg 合并、Chrome/Firefox MV3 构建、Firefox lint、PowerShell 5.1/7、真实下载、便携覆盖升级及安装覆盖/卸载冒烟。

协议边界不变：DRM/EME、SAMPLE-AES 和已经失效且无法从浏览器重新取得的签名 URL 不会被绕过。
