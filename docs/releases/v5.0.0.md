# HLS Downloader v5.0.0

能用的新版本：点浏览器下载后，确认窗来自常驻原生监督进程，不再等 WebView 启动。

- 安装包和便携包都带 `HLSNativeShell.exe`。桌面启动后拉起监督进程，预先创建确认 / 进度 / 完成窗口，再向核心登记。
- 浏览器接管热路径走 `native-shell`：文件名、链接、大小用 offer snapshot 立刻上屏，不再额外 GET。
- 托盘、主任务列表仍是现有桌面窗口；关掉列表回托盘，下载继续。
- 下载引擎不变：HTTP Range、HLS / LL-HLS / DASH、直播、BT、投屏都还在。
- 升级保留 `%LOCALAPPDATA%\HLS Downloader` 里的任务、配置和下载目录。
- 从 GitHub Release 安装 `HLSDownloader-v5.0.0-Windows-x64-Setup.exe`（或 Portable.zip）。
