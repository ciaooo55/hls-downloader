# v7.0.3-r4

修复 HLS、DASH 和直播任务成功合流后仍保留媒体分片的问题。产品版本仍为 7.0.3，安装包和浏览器插件均未签名。

- 成品成功保存、字幕复制结束后，清理任务自己的音视频分片、字幕临时数据、合流中间文件和续传检查点，再通知下载完成。
- 保留成品路径记录，支持完成后的播放、打开文件及重名文件定位。
- 失败、暂停和取消的任务保留续传数据；开启“保留临时文件”时不清理。
- 字幕复制失败时保留字幕源；清理失败记录错误，不把已保存的成品改为下载失败。
- 只处理媒体引擎生成的任务文件，保留未知文件，不处理其它任务或 BT 数据。

插件和桌面界面沿用 r3 的对应组件。本次实际验证范围、产物来源和校验值见发布附件。
