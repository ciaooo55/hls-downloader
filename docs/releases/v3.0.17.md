# HLS Downloader v3.0.17

本版本收敛浏览器媒体识别与下载接管的性能开销：无媒体页面不再常驻完整悬浮窗、轮询和观察器，媒体页面改为播放、请求和 SPA 导航事件驱动；同时过滤与媒体无关的 Fetch/XHR 和子资源请求，减少误识别与后台负载。

发布前已覆盖 Chrome/Edge 与 Firefox 的直接媒体、Shadow DOM、动态播放器、iframe、SPA、MSE、HLS、LL-HLS、DASH 和普通下载接管，并执行后端、前端、扩展、类型检查和 Firefox lint 回归。

新增中国大陆版《用户协议与免责声明》和隐私政策：首次使用需阅读完整文档并勾选“我已阅读并同意”；点击“不同意并退出”会关闭软件。接受记录仅保存协议版本、文档摘要和 UTC 时间。未确认时，前端与后端都会阻止创建、恢复、浏览器接管、BT 和投屏任务，协议正文变化后会重新提示。
