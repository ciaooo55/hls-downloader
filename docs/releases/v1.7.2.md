# HLS Downloader v1.7.2

- 修复视频旁“选择资源”浮标：按钮本身支持鼠标/触摸拖动、边界限制和位置记忆，不会因资源刷新回到原位。
- 浏览器捕获的播放请求上下文保留 5 分钟；用户播放后再选择资源时，仍会把对应 CDN 的 Cookie、Referer、User-Agent 与请求头安全传给下载器。
- 修复独立下载确认窗被全局页面最小尺寸撑大的问题；窗口按实际内容自动缩小，展开保存选项或请求上下文时再相应扩大。
- 对 Cloudflare 验证源继续保留明确诊断：仅在浏览器已有有效会话时重放已捕获上下文；不会伪造或绕过人机验证。
