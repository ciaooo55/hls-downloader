# HLS Downloader v3.0.6

## 修复

- HLS 分段下载启动时直接使用并发 worker，不再先串行预热一段播放前缀，避免 CDN 单连接限速导致速度回退。
- 浏览器捕获任务的 Referer/Origin 以实际页面 URL 为准，不再让 m3u8/CDN 域名覆盖页面访问上下文。
- Cloudflare 场景下净化浏览器指纹头，保留页面语义和必要授权，降低 403 拦截概率。
- 修复浏览器打开 `/ui` 时静态资源路径落到 `/assets` 导致黑屏的问题；现在 `/ui` 会跳转到 `/ui/`。
- 自动更新器支持版本化安装包名。

## 发布

- 桌面端、Core、Native Host 与浏览器插件统一升级到 3.0.6。
- Release 文件名现在全部包含版本号，例如 `HLSDownloader-v3.0.6-Windows-x64-Setup.exe`。
- 浏览器扩展 manifest 名称包含版本号，便于确认当前安装的插件版本。
