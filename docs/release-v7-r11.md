# v7.0.3-r11 未签名预发布版

本版补齐桌面键盘操作、插件清晰度状态、复制失败处理和字幕设置恢复。软件版本仍为 7.0.3，r11 区分交付包；安装包与插件均未签名。

## 具体修改

- 表格只在自身持有焦点时处理列表快捷键，行内按钮获得焦点后，Enter 正确执行重试等按钮动作。
- 同一资源不同清晰度按实际链接分别记录下载、投屏和 TVBox 状态；切换清晰度不会串用上一条链接的“等待确认”。资源类型和后缀也使用当前所选链接。
- 异步复制被拒后尝试同步复制并恢复按钮焦点。两种方式都失败时，在资源卡片内显示选中的只读完整链接，可直接按 Ctrl+C；复制恢复后移除手动入口。
- 字幕分栏隐藏后停止界面轮询，显示后恢复；轮询避免覆盖正在操作的选择框。
- 字幕设置保存时禁用冲突操作并阻止重复提交；失败保留新输入的 Key 并恢复清除按钮，清除失败可重试。成功后按真实配置更新状态。

未增加依赖或播放引擎。保留 r10 的行快捷操作、提示层修复、插件分栏，以及此前的主窗口播放器、边播边下和缓存清理。
