# 任务列表导入与导出

主界面“更多 → 导出任务列表”按选中任务导出；没有选中任务时导出全部。JSON 用于重新创建任务，CSV 用于查看列表，TXT/URLS 保存链接。

- JSON 一次最多 1000 项，文件不超过 1 MiB；超出时请分批选择后导出。导出前会检查这些限制，避免生成无法再导入的 JSON。
- TXT/URLS 一次最多导入 1000 个不同链接，文件不超过 256 KiB。超过数量会明确失败，不会只导入前面一部分。
- 同时选择多个文件时，一个文件失败仍继续处理后续文件，错误提示包含已创建任务数及失败文件的序号。已成功导入的任务会保留；不要把整批重新导入当作撤销操作。
- JSON 中位于当前默认下载根目录内的保存目录继续保留；其他电脑的绝对目录改用当前配置的默认下载目录。包含 `..` 的路径仍会拒绝。默认目录可在主程序设置中修改，初始值来自 Windows 下载文件夹。
- JSON 保存任务配置，不保存续传分片、运行进度、请求体、Cookie 或加密凭据，也不创建原电脑的命名队列。当前电脑已有同名 ID 的队列时保留归属，否则导入默认队列。
- JSON 不导出或导入 POST 任务，避免重建成缺少正文的错误请求。需要登录或 POST 正文的任务请重新从浏览器或 cURL 导入；CSV 可用于保留任务记录。
- 导出先写入同目录临时文件，再原子替换；写入或替换失败时保留原文件并提示错误。不支持原子替换的文件系统会明确报错。

跨环境重新导入后，文件按新任务处理，不能据列表里的旧下载字节判断已经完成。任务列表可能包含带签名参数的 URL，分享前请自行检查。
