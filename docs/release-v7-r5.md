## 源码和清理

发布附件的完整源码来自发布 tag 的 Git archive；外部 SOURCE-MAPPING 记录发布提交与构建生产源码的对应关系。包内 BUILD-PROVENANCE 保留构建时脏工作区的真实来源，未伪称从干净提交重新构建。文本源码比较明确归一 CRLF/LF。

本轮没有在本机安装，保留一个 main 分支、一个 worktree。旧安装包和本轮生成目录的删除此前被自动审批拒绝，仅返回 `blocked by policy`；代理未换方式绕过。源码中的 `scripts/finish-v3-player-cleanup.ps1` 已更新为校验 r5 和两份旧 MSI 的准确哈希，支持 `-WhatIf`，只清理本项目列明的生成目录及哈希匹配旧包；未由代理执行。用户下载、备份、注册表及其他项目不在脚本操作范围。
