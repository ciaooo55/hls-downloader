## 修复范围

- 下载成功并完成字幕复制后清理分片；暂停和失败保留续传数据。删除任务时清理其临时数据，删除任务和文件额外删除成品，保护其他文件。
- HLS/DASH 提供完整播放时间轴并优先下载所选位置；HTTP 媒体按已下载字节播放。完成后在原播放窗口切换成品，关闭的播放器不会被下载完成重新打开。
- 主界面内播放器提供进度、缓冲、独立悬停缩略图、音量、倍速、音轨、字幕、全屏和画中画。修复精确跳转、DPI 露白、预览遮挡和画中画返回黑屏。
- 字幕采用有界音频预取与服务端完成区间确认，播放追上字幕时等待；切换音轨、跳转和取消隔离旧会话。具体范围见 [字幕文档](qwencloud-subtitles.md)。
- 安装支持自选路径，默认下载目录使用当前用户的 Windows Downloads Known Folder。
- Core 与 Presenter 锁文件中的 rustls 升级至 0.23.46，修复本次安全门禁发现的公告；不新增依赖类别。

## 源码和清理

发布附件的完整源码来自发布 tag 的 Git archive；外部 SOURCE-MAPPING 记录发布提交与构建生产源码的对应关系，文本比较明确归一 CRLF/LF。最终 Core 来自 `105a1eca`；UI JAR 与插件沿用此前源码匹配的已验收构建。原生 Presenter 沿用此前已验收文件，其源文件及九个共用客户端模块与原快照经 rustfmt 比较一致；`presenter-client` 不启用 Core 的 TLS 功能模块。本地 Presenter 重编译因缺少离线 accesskit 依赖未执行成功，未把复用文件伪称为新编译；GitHub 已独立完成当前 Presenter 的测试、构建和 Clippy。

本轮没有在本机安装，保留一个 main 分支、一个 worktree。旧安装包和本轮生成目录的删除此前被自动审批拒绝，仅返回 `blocked by policy`；代理未换方式绕过。源码中的 `scripts/finish-v3-player-cleanup.ps1` 已更新为校验 r5 和两份旧 MSI 的准确哈希，支持 `-WhatIf`，只清理本项目列明的生成目录及哈希匹配旧包；未由代理执行。用户下载、备份、注册表及其他项目不在脚本操作范围。
