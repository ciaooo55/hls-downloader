# v7.0.3-r10 未签名预发布版

本版改进桌面与浏览器插件的日常操作，修复提示浮层遮挡按钮和 Firefox 弹窗底部裁切。软件版本仍为 7.0.3，r10 区分交付包；安装包与插件均未签名。

## 具体修改

- 桌面任务行提供适用的暂停、继续、重试、播放或打开目录快捷操作，改善小窗口操作列、工具栏对比、按压和键盘焦点反馈。
- 任务失败通知改为主窗口内的 dp 布局，避免 150% 缩放时遮住主题按钮；模态界面期间隐藏，计时仍继续。已在前台的窗口收到失败事件时保留当前焦点。
- 用现有框架提示替换自绘 Tooltip Popup，修复提示层滞留遮挡相邻按钮。任务列表派生结果缓存，图片详情进入预览后才解码，切换标签复用。
- 插件划分资源、字幕、设置标签，字幕首次进入才挂载；支持方向键、Home/End 切换和正确的焦点状态。
- 清晰度使用原生选择框，重绘保留焦点和滚动；连续复制保留图标且反馈按时恢复，下载等待、确认、入队、重试状态区分显示，成功后停止转圈。
- 设置明确说明全局接管和本站设置，保存期间阻止重复操作；Firefox 原生弹窗限高 600 CSS px，列表在可用区域滚动。

没有新增依赖或播放引擎。保留 r9 的断流恢复、精简依赖、主窗口播放器浮层、画中画、边播边下、完整时间轴，以及完成和删除任务后的缓存清理。

## 实际验收

- 插件类型检查、Chromium/Firefox 构建通过，50 个测试文件共 380 项通过。两个插件 ZIP 与构建目录逐文件一致，Firefox 审核源码单独提供。
- 桌面构建及 54 项定向测试通过。最终同一 JAR 在沙盒中完成 100% 和 Java 模拟 150% 两档、各 13 项实际交互，包括通知显示时点击、行暂停/恢复/重试、键盘操作、浮层播放与关闭、筛选清理、成品保留和小窗口布局。
- Firefox 原生工具栏弹窗两档各 5 项通过，覆盖浅深色滚动、键盘标签、字幕懒挂载、清晰度与真实系统剪贴板；另有 15 项完整交互通过，含插件点击→桌面确认→实际下载及 SHA256 核对。15 项流程在最终仅调整弹窗限高之前执行，最终限高后已重测两档原生弹窗。
- 最终 r10 MSI 在干净 Windows Sandbox 中完成 9 项安装验收：自选含空格路径、生产组件哈希、插件 ZIP 与解包文件一致、系统 Downloads 默认路径、真实 MDN 视频下载逐字节一致、完成缓存清除、界面连接、资源测量及卸载记录移除。静态核对安装目录选择对话框及其标准 WiX 间接绑定存在。
