# v7.0.3-r6 未签名预发布版

2026-10-17。本轮修复网页解密媒体的悬浮窗归属，以及字幕预取对伪装后缀分片、无后缀 HLS 清单的解码。安装包与插件均未签名，不包含用户密钥、任务库或下载文件。

## 修复与验证

- 页面使用 WebCrypto 解密后向 MSE 追加媒体时，保留原请求的媒体归属，使悬浮窗能够绑定对应视频。解密结果不继承普通 Blob 下载归属，避免把解密后的文件错误重放成服务器原始响应。未记录密钥，也未改变页面解密结果。
- 已识别的 HLS 字幕音频输入显式使用 HLS 解复用器，允许非标准分片后缀；输入协议仍限制为 HTTP/HTTPS、TCP/TLS 和 crypto。远程清单读取本地文件的反例实际验证为失败。
- 沙盒中旧插件的加密媒体场景失败，当前插件同场景通过；Edge 23 个媒体归属场景全部通过。插件类型检查、380 项测试、Chromium/Firefox 构建与打包通过；Firefox 扩展校验为零错误、零警告、零提示。Firefox 随后在新沙盒实际通过直接媒体、MSE、DASH MSE 和 WebCrypto 解密四个场景，使用临时配置，未操作用户浏览器配置。
- 沙盒 Core 全量测试 600 passed、3 ignored；其中新增的音频解码 ignored 测试用真实 fixture 单独执行通过。该专项实际解码伪装 `.jpeg` 分片、无后缀 HLS 和普通 M4A，检查输出非静音，并验证本地文件访问被拒绝。
- 旧 FFmpeg 参数在伪装分片上复现 `0xbebbb1b7`，修复后实际输出 32,000 字节音频。该结果解释了一种相同错误码的成因，不能替代原用户视频的下载验收。
- 三组浏览器字幕回归通过：预取、元素音频和标签页音频。使用真实插件、浏览器音频与 Native Host，翻译服务为 fixture Core；不代表真实云端翻译准确性、质量或延迟已验收。
- 21 项下载、边播边下和缓存回归通过，覆盖 TS、伪装后缀、fMP4、AES、独立音轨、DASH、HTTP、未完成时跳转解码、同窗切换成品、关闭不重开、暂停续传、完成与删除任务清理，以及保留无关文件。Core 最后经 rustfmt 重新编译后，使用与最终 MSI 中引擎哈希一致的文件再次跑完 21 项，全部通过。

## 明确未闭环的范围

原用户网页在沙盒 Edge 被 SmartScreen 安全提示阻挡，没有绕过；原 surrit 清单返回 HTTP 403，因此原网页和原视频未通过实际验收。HLS.js 与 MDN 公开页面通过；DASH 官方样例的清单请求连续约十秒超时，视频没有建立 MSE 播放，未计为通过。不能把资源列表中的某个清单强行绑定到未开始播放的视频。

本轮播放器首次复验被 Core 测试程序遗留的 Windows 防火墙提示阻挡，用户取消提示后重新执行，九组实际交互全部通过：暂停/播放、画面点击、跳转、进度拖动、音量/静音、倍速、音轨与字幕、独立缩略图、全屏、画中画拖动与返回、关闭和重新打开。UI 和 Presenter 源码未修改，复用 r5 经哈希核对的构建。

真实云端字幕本轮未重跑。投屏、TVBox 按既定范围排除。BT 未完成任务、直播和未知长度 HTTP 的边播边下不在已支持范围。禁用 GPU 沙盒的边下边播 CPU 样本约占整机 54.6%，仍不能宣称播放性能问题全面解决。
