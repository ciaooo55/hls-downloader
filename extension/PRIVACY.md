# 浏览器插件隐私说明

更新日期：2026 年 10 月 11 日。适用于 HLS Downloader 浏览器插件 7.0.3。

插件在浏览器内识别下载链接、网页媒体和请求信息，保存设置及当前页面的识别结果。开发者不接收这些信息，不运营分析、广告或遥测服务。

接管 POST 下载或网页生成的 Blob/data 导出时，插件向本机桌面程序发送已完成的浏览器文件路径、大小和来源页面。桌面程序经确认后读取并复制本地文件，成功完成任务后插件删除浏览器副本；拒绝或复制失败保留原文件。POST 下载的自动接管不会再次提交原请求。文件内容不会因此上传给开发者。

用户选择下载时，插件通过 Native Messaging 将资源 URL、页面来源、标题、媒体信息和重放请求所需的上下文发送给同一台 Windows 电脑上的 HLS Downloader。桌面程序随后向用户选择的网站或下载服务器发起请求。站点 Cookie 默认不读取；用户在插件中为站点明确授权后，才向本机桌面程序发送该站点下载所需的 Cookie。已捕获的鉴权请求头和短效签名 URL 可能包含登录凭据，请勿公开分享。

在线字幕默认关闭。用户配置百炼业务空间和 API Key、启用字幕并点击“开始翻译”后，插件采集当前网页媒体的音频，通过本机桌面程序发送给用户选择的百炼服务地域，用于识别和翻译。启用预翻译时，程序会提前读取当前音轨，最多预采集 30 秒。开发者不接收音频、API Key 或译文，也不提供共享账户。API Key 由桌面程序使用 Windows DPAPI 加密保存。

用户可以关闭下载接管、撤销站点 Cookie 授权、关闭或停止字幕、清除字幕 API Key、删除本机下载任务，或者卸载插件。插件设置保存在浏览器本地，任务与凭据保存在本机桌面程序的数据目录。桌面程序和用户主动连接的第三方服务各自处理其收到的数据。

Firefox 清单声明浏览活动、网页内容和鉴权信息的传输，覆盖向本机 Native Messaging 程序发送的内容。该声明不表示开发者运营接收这些数据的服务器。

问题反馈：<https://github.com/ciaooo55/hls-downloader/issues>。请勿在公开反馈中附带 Cookie、Authorization、API Key、音频或包含签名参数的 URL。
